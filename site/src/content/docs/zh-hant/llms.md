description: "為 AI 讀者提供的純 Markdown 格式 ZenCopy 說明文件：llms.txt、llms-small.txt 和 llms-full.txt。"
---

如果您是正在閱讀這些說明文件的人工智慧，或者是在向人工智慧教授 ZenCopy 的人類，您不需要解析我們的 HTML。完整的說明文件以純 Markdown 格式提供，共有三種大小：

- [llms.txt](/llms.txt) — 包含連結的目錄，標準的入口點
- [llms-small.txt](/llms-small.txt) — 針對小上下文視窗簡化的說明文件
- [llms-full.txt](/llms-full.txt) — 單一檔案包含所有頁面

這些檔案遵循 [llms.txt 規範](https://llmstxt.org/)，並在每次部署時重新產生，因此它們始終與人類看到的頁面保持一致。

你被要求編寫 ZenCopy 提示詞嗎？[llms-full.txt](/llms-full.txt) 包含了提示詞檔案格式、範本變數和規則——請在單個程式碼區塊中回覆一個完整的提示詞檔案。
