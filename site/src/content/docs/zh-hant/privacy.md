ZenCopy 是一款本機桌面應用程式。
沒有伺服器、沒有帳號，也沒有遙測。

## 哪些內容會離開你的裝置

當你按下觸發鍵（<span data-os-modifier>Ctrl/⌘</span> + C + C）時，擷取到的剪貼簿內容會直接送到*你*設定的 LLM 供應商——僅此而已，也不會送到其他任何地方。
確切送出什麼，取決於執行的動作：

- 算繪後的提示詞，其中可能以[範本變數](/zh-hant/configuration/#actionsmd)嵌入這次擷取的情境：複製的文字與標記、來源應用程式的名稱與視窗標題、頁面 URL、日期，以及你的語系。
- 若是圖片或複製的檔案，內容本身會被附加（每次擷取上限 10 MB）——檔案還會附上完整路徑。
  預設情況下，彈出視窗會在送出這些內容前先詢問。

平常的單次複製絕不會被擷取，也絕不會被送出。
被其他應用程式（例如密碼管理器）標示為機密的剪貼簿內容會被忽略。

## 哪些內容留在你的裝置上

- 你的 API 金鑰（應用程式設定目錄中的 `ai-sdk-catalog.json`——絕不隨附打包，也絕不上傳）。
- 你的設定（主題、語言、彈出視窗位置……）。
- 記錄檔。
  記錄會遮蔽機密資訊，且絕不包含複製的內容或 API 金鑰。

## 第三方

你對 LLM 供應商的使用，受該供應商自身的條款與隱私權政策約束。
ZenCopy 不加入任何中介：你的內容只會送到你設定的供應商，其使用方式與費用由你自行負責。

## 不必只聽我們說

ZenCopy 是開放原始碼軟體（Apache-2.0）。
本頁的每一項聲明，都可以對照[原始碼](https://github.com/sincekmori/zencopy)驗證。

## 這個網站

zencopy.app 是靜態網站。
它不設定任何 cookie，也不執行任何分析工具。
