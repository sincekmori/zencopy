ZenCopy 是一個能在任何應用程式之上喚出 AI 對話的工具。
只要會複製，就會用。
要學的只有一件事——**把平常的複製，快速按兩次**。
光是這樣，AI 對你剛選取內容的回答就會出現在螢幕角落，**而且可以在它下方的輸入欄就地繼續對話**。
在任何應用程式上，用法都完全相同。

## ZenCopy 每天能為你做什麼 {#what-zencopy-does-for-you-every-day}

- 選取長篇報告或文章，**幾行字掌握重點**
- 把外語網頁或聊天內容**當場變成你的語言**
- 讓陌生術語、錯誤畫面、合約條文**用白話解釋清楚**
- 交出電子郵件或文章的粗略草稿，**幫你修整妥當**
- 然後接著回答繼續問：**「再詳細一點」「整理成表格」「所以到底是什麼意思？」**——想問多少問多少

步驟永遠相同：選取，然後複製兩次。
不必開啟聊天網站，也不必找地方貼上。
**想問 AI 的時候，先複製兩次再說**——這就是 ZenCopy 用法的全部。

## 你需要準備的東西 {#what-you-need}

1. **一台電腦** — ZenCopy 可在 Windows、macOS 和 Linux 上執行。
   （支援的 Linux 環境範圍請見[常見問題](/zh-hant/faq/)。）
2. **一個 Google 帳號** — 你會建立一串稱為「API 金鑰」的長字串，用來免費使用 AI。
   如果沒聽過這個詞也不用擔心：本頁會一步步帶你完成。

## 準備免費的 AI 金鑰 {#prepare-a-free-ai-key}

ZenCopy 本身免費，但實際的摘要與翻譯是由外部 AI 完成的——就是你可能已經透過 Gemini 或 ChatGPT 用過的那種 AI。
讓你自己的應用程式能使用這類 AI 的鑰匙，就是 **API 金鑰**——一串長長的字串。
把它想成家裡的鑰匙：**它只屬於你，絕對不要給任何人看**。
關於它，記住這一點就夠了。

最簡單的選擇是 Google 的免費金鑰：

<Steps>

1. 開啟 [Google AI Studio 的 API 金鑰頁面](https://aistudio.google.com/api-keys)，用你的 Google 帳號登入。

2. 按下 **Create API key** 按鈕。

3. 複製畫面上出現的長字串（以 `AIza…` 開頭）。
   那就是你的 API 金鑰。

</Steps>

以個人使用來說，免費額度已經足夠，而且**完全免費：只要不新增付款方式，就不可能被收費**。
即使達到免費額度的上限，也不會產生任何費用——請求只是會暫停一段時間。
有一點值得知道：**在 Google 的免費方案中，你傳送的內容可能會被用於改進其服務**（依 Google 的條款）。
如果會處理機密的工作文件，請改用付費方案，或選擇[其他 AI 或本機 AI](/zh-hant/configuration/)。

## 首次啟動 {#first-launch}

1. 啟動 ZenCopy 不會立刻開啟視窗。
   它會安靜地待在螢幕邊緣的小圖示區（Windows 是工作列右下角，Mac 是頂端的選單列）。
2. 第一次啟動時，會出現簡短的歡迎畫面。
   貼上剛剛複製的 API 金鑰，按下**使用此金鑰開始**。
   **設定就完成了。**
3. 你複製的內容會**直接**傳送到你設定的 AI 服務。
   中間沒有中繼伺服器，也沒有使用追蹤。

想使用 Google 以外的 AI（OpenAI、Anthropic、企業閘道、本機 Ollama 等），請選擇**用其他方式設定**，再到設定中挑選。

## 日常使用 {#everyday-use}

1. 在任何應用程式中選取文字，按 **<span data-os-modifier>Ctrl/⌘</span> + C + C**。
2. 螢幕角落會出現彈出視窗，結果隨即逐字顯示。
3. 結果上方的標籤（「摘要」、「翻譯」……）是一個**切換器**。
   點它，就能對同一份複製內容執行不同的提示詞。
   看過的結果都會保留，切換回去是即時的——只有**重試**會重新執行提示詞。
   按標籤旁的 ☆，即可把該提示詞設為新的預設。
4. 每則回覆下方都有小小的**複製**和**重試**按鈕 — 重試會把對話倒回該則回覆並重新執行 — 生成中的回覆可以**停止**。
   在結果下方的輸入框中回覆，即可就地繼續對話。
   按 **Esc** 或點關閉按鈕即可關閉；拖曳標題列可移動，拖曳邊緣可調整大小。
5. 太快關掉結果了嗎？常駐選單裡的**顯示應用程式**隨時能叫回上一個結果。

內建四個提示詞：
**摘要**（濃縮成一句話）、**解說**（把內容變得易懂）、**翻譯**（翻成你的語言）、**潤飾**（修整草稿）。
自訂提示詞只需要一個名稱，加上一句你想要它做的事（見[設定](/zh-hant/configuration/)）。

而且不只限於文字。
螢幕截圖與複製的檔案（圖片、PDF、音訊、文字檔案）都用同一個手勢處理。
在傳送圖片或其他二進位檔案之前，ZenCopy 會先向你確認一次。

## 以安全為前提的設計 {#designed-to-be-safe}

- **平常的單次複製什麼都不會發生。**不讀取，也不傳送。
- 被其他應用程式（例如密碼管理器）標示為機密的剪貼簿內容，即使複製兩次也會被忽略。
- 內容只會送到你自己設定的 AI 服務。
