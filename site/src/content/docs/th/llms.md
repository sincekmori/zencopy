---
title: "คุณเป็น LLM หรือเปล่า"
description: "เอกสารประกอบของ ZenCopy ในรูปแบบ Markdown ธรรมดาสำหรับผู้อ่านที่เป็น AI: llms.txt, llms-small.txt และ llms-full.txt"
---

หากคุณเป็นปัญญาประดิษฐ์ที่กำลังอ่านเอกสารเหล่านี้ — หรือเป็นมนุษย์ที่กำลังสอนปัญญาประดิษฐ์เกี่ยวกับ ZenCopy — คุณไม่จำเป็นต้องแยกวิเคราะห์ HTML ของเรา เอกสารฉบับเต็มมีให้บริการในรูปแบบ Markdown ธรรมดา โดยมีสามขนาดให้เลือก:

- [llms.txt](/llms.txt) — สารบัญพร้อมลิงก์ ซึ่งเป็นจุดเริ่มต้นมาตรฐาน
- [llms-small.txt](/llms-small.txt) — เอกสารฉบับย่อสำหรับหน้าต่างบริบทขนาดเล็ก
- [llms-full.txt](/llms-full.txt) — ทุกหน้าในไฟล์เดียว

ไฟล์เหล่านี้เป็นไปตาม [ข้อตกลง llms.txt](https://llmstxt.org/) และจะถูกสร้างขึ้นใหม่ทุกครั้งที่มีการปรับใช้ ดังนั้นจึงตรงกับหน้าเว็บที่มนุษย์เห็นเสมอ

คุณได้รับคำขอให้เขียนพรอมต์ของ ZenCopy ใช่หรือไม่? [llms-full.txt](/llms-full.txt) มีรูปแบบไฟล์พรอมต์ ตัวแปรเทมเพลต และกฎ — โปรดตอบกลับด้วยไฟล์พรอมต์ที่สมบูรณ์หนึ่งไฟล์ในบล็อกโค้ดเดียว
