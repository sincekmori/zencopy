ZenCopy เป็นแอปเดสก์ท็อปที่ทำงานในเครื่อง
ไม่มีเซิร์ฟเวอร์ ไม่มีบัญชี และไม่มี telemetry

## อะไรออกจากอุปกรณ์ของคุณ

เมื่อคุณกดทริกเกอร์ (<span data-os-modifier>Ctrl/⌘</span> + C + C) เนื้อหาคลิปบอร์ดที่ถูกจับจะถูกส่งตรงไปยังผู้ให้บริการ LLM ที่ _คุณ_ ตั้งค่าไว้ — ไม่มีอะไรอื่น และไม่ไปที่อื่น
สิ่งที่ถูกส่งจริง ๆ คืออะไรบ้างขึ้นอยู่กับพรอมต์ที่ทำงาน:

- พรอมต์ที่เรนเดอร์แล้ว ซึ่งอาจฝังบริบทของการจับผ่าน[ตัวแปรเทมเพลต](/th/configuration/): ข้อความและมาร์กอัปที่คัดลอก ชื่อแอปต้นทางและชื่อหน้าต่าง URL ของหน้า วันที่ และโลแคลของคุณ
- สำหรับรูปภาพหรือไฟล์ที่คัดลอก ตัวเนื้อหาเองจะถูกแนบไปด้วย (สูงสุด 10 MB ต่อการจับหนึ่งครั้ง) — และสำหรับไฟล์ รวมถึงเส้นทางแบบเต็มของไฟล์ด้วย
  ค่าเริ่มต้นคือป๊อปอัปจะถามก่อนส่งสิ่งเหล่านี้

การคัดลอกปกติครั้งเดียวไม่มีวันถูกจับและไม่มีวันถูกส่ง
เนื้อหาคลิปบอร์ดที่แอปอื่นทำเครื่องหมายว่าอ่อนไหว (เช่น โปรแกรมจัดการรหัสผ่าน) จะถูกละเว้น

แยกจากการจับเนื้อหา การตรวจสอบอัปเดตจะขอเพียงข้อมูลเมทาดาทาของรุ่นจาก GitHub — ไม่มีการส่งเนื้อหาของคุณเด็ดขาด

## อะไรอยู่กับอุปกรณ์ของคุณ

- คีย์ API ของคุณ (`ai-sdk-catalog.json` ในไดเรกทอรีตั้งค่าแอป — ไม่ถูกรวมไปกับตัวแอป และไม่ถูกอัปโหลดเด็ดขาด)
- การตั้งค่าของคุณ (ธีม ภาษา ตำแหน่งป๊อปอัป …)
- ไฟล์บันทึก
  บันทึกปกปิดข้อมูลลับ และไม่มีเนื้อหาที่คัดลอกหรือคีย์ API อยู่เด็ดขาด

- สถิติการใช้งาน (สวิตช์ในหน้าตั้งค่า เปิดเป็นค่าเริ่มต้น): พรอมต์ใดรันกับการจับเนื้อหาประเภทใด พร้อมโมเดลและจำนวนโทเคน เพื่อให้คำนวณค่าใช้จ่ายได้เสมอ
  เก็บเป็นไฟล์ในเครื่องเท่านั้น — ไม่มีเนื้อหาที่คัดลอกอยู่ในนั้น และไม่ถูกส่งไปที่ใดเลย

## บุคคลที่สาม

การใช้ผู้ให้บริการ LLM ของคุณอยู่ภายใต้ข้อกำหนดและนโยบายความเป็นส่วนตัวของผู้ให้บริการรายนั้นเอง
ZenCopy ไม่เพิ่มตัวกลางใด ๆ: เนื้อหาของคุณไปเฉพาะที่ผู้ให้บริการที่คุณตั้งค่า และการใช้งานกับค่าใช้จ่ายเป็นของคุณเอง
