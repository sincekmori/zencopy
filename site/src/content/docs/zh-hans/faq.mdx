## 需要付费吗？ {#does-it-cost-money}

ZenCopy 本身是免费的开源软件（Apache-2.0）。
没有账号，也没有订阅。

AI 服务收不收费，是你和那家服务之间的事。
使用 [Google 的免费额度](/zh-hans/getting-started/)则完全免费 — 只要不登记付款方式，就不可能被扣费。
而如果用完全在你自己电脑上运行的 AI（例如 Ollama），根本就不存在需要付费的外部服务。

## 我复制的内容会去哪里？ {#where-does-my-copied-content-go}

只有当你复制两次时，内容才会**直接发送给你配置的 AI 服务** — 除此之外哪里都不去。
没有 ZenCopy 的服务器，没有中转，也没有使用情况追踪（遥测）。
你的 API 密钥同样绝不离开你的电脑。

## 普通的复制会触发什么吗？ {#does-an-ordinary-copy-trigger-anything}

不会。
单独一次 <span data-os-modifier>Ctrl/⌘</span> + C 什么都不启动、什么都不读取、什么都不发送。
只有快速连续的两次复制才是信号。

## AI 的回答有多可信？ {#how-much-can-i-trust-the-ais-answers}

AI 可能一本正经地说错话。
用它把握一段文字的大意确实很有用，但涉及数字、名称，以及任何后果重大的内容 — 合同、医疗文本 — 请先对照原文核实，再据此行动。

## 它和其他“选中即用 AI”的工具有什么不同？ {#how-is-this-different-from-other-ai-on-selection-tools}

这个领域的多数工具只支持 macOS、只处理选中的文本，并且绑定在某一家的 AI 或某种订阅上。
ZenCopy 运行在 **Windows、macOS 和 Linux** 上，能处理**文本、图片和文件**，并且 **AI 服务由你来选**（OpenAI / Google / Anthropic / 企业网关 / 本地 Ollama）。
而且不止一问一答。你可以从答案下方的输入框**就地继续对话**。
[运行哪个提示词也由你决定](/zh-hans/configuration/#rulesjson)。
无账号、无订阅、无遥测 — 开源软件。

## 和 ChatGPT 之类的聊天网站有什么不同？ {#how-is-this-different-from-chat-sites-like-chatgpt}

聊天网站是要“走过去”才能说话的地方。
ZenCopy 则**把对话唤到你正在看的东西上面**。
选中，复制两次 — 正在读的文章、错误画面的截图、收到的 PDF，无需粘贴就直接成为对话的起点。
第一条回答（摘要、翻译等）自动开始，之后就和普通聊天一样。
模型由你自己选，历史不会留在任何服务器上（对话只存续到下一次复制为止，仅限当场）。

## 另一个应用也响应 Ctrl/⌘ + C + C（例如 DeepL） {#another-app-also-reacts-to-ctrl--c--c-eg-deepl}

没有任何应用能在操作系统层面独占“复制两次”这个信号。
如果另一个应用也在监听同一个信号（DeepL 是最有名的一个），**两边**都会响应，出现两个弹窗。
ZenCopy 不拦截、不屏蔽任何按键事件，所以不会有东西坏掉 — 症状仅此而已。
在你用得较少的那个应用里关掉这个快捷键即可（DeepL：设置 → 通用 → 翻译快捷键）。

## 弹窗一直不出现（macOS） {#the-popup-never-appears-macos}

几乎可以肯定是权限问题。
在系统设置 → 隐私与安全性中，为 ZenCopy 允许**输入监控**，然后退出并重新启动应用。
（应用正是靠这项权限来察觉复制被按了两次。）

## 没有返回结果 / 提示超时 {#no-result-comes-back--it-says-it-timed-out}

如果响应静默超过 90 秒，ZenCopy 会判定这次运行失败，而不是无限等下去。
请检查网络连接和 AI 服务的设置（API 密钥等），然后点**重试**。
本地 AI 第一次加载可能需要一段时间，所以这个超时时间特意设得比较宽裕。

## 支持哪些 Linux 环境？ {#which-linux-environments-are-supported}

**Wayland 上的 GNOME，以及 X11。**
在 GNOME Wayland 上，后台进程在设计上无法观察按键或剪贴板，所以 ZenCopy（通过 [`copycopy`](https://crates.io/crates/copycopy) crate）附带了一个小型 GNOME Shell 扩展，从合成器内部检测两次复制。
它在首次启动时自动安装到你的用户配置目录（无需 sudo），注销并重新登录一次后生效。
在 X11 上，和 Windows 一样，普通的被动按键监听即可工作。
其他 Wayland 合成器（KDE Plasma、基于 wlroots 的）没有提供无特权观察触发信号的途径，目前不支持 — 应用可以运行，但触发器保持沉默。

## 托盘图标不显示（Linux） {#the-tray-icon-does-not-show-up-linux}

ZenCopy 的托盘图标使用 AppIndicator 协议。
Ubuntu 的 GNOME 开箱即支持，但原版 GNOME（例如 Fedora）在安装 **AppIndicator and KStatusNotifierItem Support** 这个 Shell 扩展之前什么都不显示。
无论哪种情况，应用本身都正常工作 — 托盘菜单只是入口之一。
