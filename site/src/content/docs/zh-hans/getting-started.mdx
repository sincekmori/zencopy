只要会复制，就会用 ZenCopy。
需要学的只有一件事 — **像平时一样复制，只需快速按两次**。
仅此一下，你刚选中的内容的摘要、翻译、解释或润色稿就会出现在屏幕角落。
在任何应用中，它的工作方式都完全一样。

## ZenCopy 每天能为你做什么

- 选中一篇长报告或长文章，**用几行字拿到要点**
- 把外语页面或聊天内容**当场变成你的语言**
- 让陌生的术语、错误提示、合同条文**用大白话解释清楚**
- 把邮件或文章的粗略草稿交给它，**直接帮你理顺**

步骤永远一样：选中，然后复制两次。
不用切换应用，也不用找地方粘贴。

## 你需要准备

1. **一台电脑** — ZenCopy 支持 Windows、macOS 和 Linux。
   （Linux 的支持范围见 [FAQ](/zh-hans/faq/)。）
2. **一个 Google 账号** — 你将创建一串叫“API 密钥”的长字符串，用来免费使用 AI。
   如果这个词对你很陌生，别担心：本页会一步一步带你完成。

## 准备免费的 AI 密钥

ZenCopy 本身是免费的，但实际执行摘要和翻译的是外部 AI — 和你可能已经通过 Gemini 或 ChatGPT 用过的是同一类 AI。
让你自己的应用能够使用这种 AI 的钥匙，就是 **API 密钥** — 一串长字符串。
把它当作家门钥匙就好：**只属于你自己，绝不给任何人看**。
关于它，记住这一点就够了。

最简单的选择是 Google 的免费密钥：

<Steps>

1. 打开 [Google AI Studio 的 API 密钥页面](https://aistudio.google.com/api-keys)，用你的 Google 账号登录。

2. 点击 **Create API key**（创建 API 密钥）按钮。

3. 复制出现的那串长字符串（以 `AIza…` 开头）。
   这就是你的 API 密钥。

</Steps>

个人使用的话免费额度已经足够，而且**完全免费：只要不登记付款方式，就不可能被扣费**。
即使用到了免费额度的上限，也不会产生费用 — 请求只是暂停一段时间。
有一点值得了解：**在 Google 的免费额度下，你发送的内容可能会被用于改进其服务**（依 Google 的条款）。
如果要处理工作中的机密文件，请改用付费方案，或选择[其他 AI 或本地运行](/zh-hans/configuration/)。

## 首次启动

1. 启动 ZenCopy 后不会立刻打开窗口。
   它会驻留在屏幕边缘的小图标区（Windows 在任务栏右下角，Mac 在顶部菜单栏）。
2. 第一次启动时会打开一个简短的欢迎界面。
   粘贴刚才复制的 API 密钥，点击**用这个密钥开始**。
   **设置到此完成。**
3. 你复制的内容会**直接**发送给你配置的 AI 服务。
   中间没有任何中转服务器，也没有使用情况追踪。

想使用 Google 以外的 AI（OpenAI、Anthropic、企业网关、本地 Ollama 等），选择**用其他方式设置**，在设置中挑选即可。

### 关于权限

    - **系统设置 → 隐私与安全性 → 输入监控** — 允许 ZenCopy

    这项权限只是为了让应用察觉那个**信号** — 不是为了读取你的屏幕。

    GNOME 在登录时加载新扩展，所以首次启动后请**注销并重新登录一次**。
    在扩展生效之前，欢迎界面和设置界面会一直提醒你。
    在 X11 上，启动后即可使用。
  </TabItem>

## 日常使用

1. 在任何应用中选中文本，按 **<span data-os-modifier>Ctrl/⌘</span> + C + C**。
2. 弹窗出现在屏幕角落，结果流式地显示出来。
3. 结果上方的标签（“Zen”“翻译”……）是一个**切换器**。
   点击它，可以对同一份复制内容运行别的动作。
   看过的结果会保留下来，切回去是瞬间的 — 只有**重试**才会重新运行动作。
   点击标签旁的 ☆，可以把该动作设为新的默认。
4. 在弹窗里，你可以**停止**正在运行的动作、**重试**，或**复制**结果。
   按 **Esc** 或点击关闭按钮即可关闭；拖动标题栏可移动，拖动边缘可调整大小。
5. 结果关得太快了？随时可以用托盘菜单里的**显示应用**找回上一个结果。

内置了四个动作：
**Zen**（浓缩成一句话）、**解释**（讲到你能听懂）、**翻译**（译成你的语言）、**润色**（把草稿理顺）。
添加自定义动作，只需要一个名称和一份对你想要执行的操作的描述（见[配置](/zh-hans/configuration/)）。

而且不只是文本。
截图和复制的文件（图片、PDF、音频、文本文件）也用同一个手势处理。
在发送图片或其他二进制文件之前，ZenCopy 会先向你确认一次。

## 为安心而设计

- **普通的一次复制，什么都不会发生。** 不读取，也不发送。
- 被其他应用（例如密码管理器）标记为机密的剪贴板内容，即使复制两次也会被忽略。
- 内容只会发送给你自己配置的 AI 服务。
