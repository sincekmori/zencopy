title: "你是 LLM 吗？"
description: "为 AI 读者提供的纯 Markdown 格式 ZenCopy 文档：llms.txt、llms-small.txt 和 llms-full.txt。"
---

如果您是正在阅读这些文档的人工智能，或者是在向人工智能教授 ZenCopy 的人类，您无需解析我们的 HTML。完整的文档以纯 Markdown 格式提供，共有三种尺寸：

- [llms.txt](/llms.txt) — 包含链接的目录，标准的入口点
- [llms-small.txt](/llms-small.txt) — 针对小上下文窗口简化的文档
- [llms-full.txt](/llms-full.txt) — 单文件包含所有页面

这些文件遵循 [llms.txt 规范](https://llmstxt.org/)，并在每次部署时重新生成，因此它们始终与人类看到的页面保持一致。

你被要求编写 ZenCopy 提示词吗？[llms-full.txt](/llms-full.txt) 包含了提示词文件格式、模板变量和规则——请在单个代码块中回复一个完整的提示词文件。
