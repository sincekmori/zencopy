ZenCopy 是一个本地桌面应用。
它没有服务器，没有账号，也没有遥测。

## 哪些内容会离开你的设备 {#what-leaves-your-device}

当你按下触发键（<span data-os-modifier>Ctrl/⌘</span> + C + C）时，捕获到的剪贴板内容会直接发送给*你*配置的 LLM 提供商 — 除此之外没有别的内容，也没有别的去处。
具体发送什么，取决于运行的提示词：

- 渲染后的提示词，其中可以通过[模板变量](/zh-hans/configuration/#promptsmd)嵌入这次捕获的上下文：复制的文本和标记、来源应用的名称和窗口标题、页面 URL、日期，以及你的语言区域。
- 对于图片或复制的文件，内容本身会被附加（每次捕获上限 10 MB）— 文件还会附上完整路径。
  默认情况下，弹窗会在发送这些内容前先询问。

普通的一次复制永远不会被捕获，也永远不会被发送。
被其他应用（例如密码管理器）标记为敏感的剪贴板内容会被忽略。

与捕获无关，检查更新时只会向 GitHub 请求版本元数据——绝不会发送你的内容。

## 哪些内容留在你的设备上 {#what-stays-on-your-device}

- 你的 API 密钥（应用配置目录里的 `ai-sdk-catalog.json` — 绝不打包，绝不上传）。
- 你的设置（主题、语言、弹窗位置……）。
- 日志文件。
  日志会对密钥脱敏，并且绝不包含复制的内容或 API 密钥。

- 使用统计（设置中的开关，默认开启）：哪个提示词处理了哪种捕获，以及模型和 token 数量，让费用始终可以计算。
  仅保存为本地文件——绝不含复制的内容，绝不发送到任何地方。

## 第三方 {#third-parties}

你对 LLM 提供商的使用受该提供商自己的条款和隐私政策约束。
ZenCopy 不加入任何中间环节：你的内容只发送给你配置的提供商，其使用方式和费用由你自己承担。
