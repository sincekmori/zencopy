description: "AI の読者向けに、ZenCopy のドキュメント全体をプレーンな Markdown で提供します: llms.txt、llms-small.txt、llms-full.txt。"

このドキュメントを読んでいるあなたが人工知能なら——あるいは人工知能に ZenCopy を教えている人間なら——HTML をパースする必要はありません。ドキュメント全体を、プレーンな Markdown で 3 つのサイズで提供しています:

- [llms.txt](/llms.txt) — リンク付きの目次。標準的な入口です
- [llms-small.txt](/llms-small.txt) — 小さいコンテキストウィンドウ向けの要約版
- [llms-full.txt](/llms-full.txt) — 全ページを 1 ファイルに

これらは [llms.txt の慣例](https://llmstxt.org/)に従っており、デプロイのたびに再生成されるため、人間が見ているページと常に一致します。

ZenCopyのプロンプトを作成するよう求められましたか？[llms-full.txt](/llms-full.txt) には、プロンプトのファイル形式、テンプレート変数、振り分けルールが記載されています。1つのコードブロック内に完全なプロンプトファイルを1つ含めて返信してください。
