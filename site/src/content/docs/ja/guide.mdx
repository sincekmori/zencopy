長い記事、外国語のチャット、意味のわからないエラー画面。
読んでいるものを選んで、いつものコピーをすばやく 2 回。
それだけで、今見ている画面の隅に AI の答えが現れます。
ZenCopy は、そのための無料アプリです。

はじめるためにやることは 3 つ、インストール、AI をつなぐ、コピー 2 回。
全部で 10 分です。

## 1. インストール {#install}

[GitHub Releases](https://github.com/sincekmori/zencopy/releases/latest) から、お使いの OS のインストーラーをダウンロードします:

<Tabs syncKey="os">
  <TabItem label="Windows">
    <DownloadLink kind="windows" /> をダウンロードして実行します。
    「WindowsによってPCが保護されました」と出たら、「詳細情報」→「実行」で進めてください。 Windows
    がまだ知らない新しいアプリに対して一度だけ出る確認です。
  </TabItem>
  <TabItem label="macOS">
    <DownloadLink kind="dmg" /> を開き、ZenCopy を**アプリケーション**フォルダへドラッグします。
    初回起動時に macOS が一度だけ確認してくるので、「開く」を選択してください。
  </TabItem>
  <TabItem label="Linux">
    <DownloadLink kind="appimage" /> をダウンロードし、実行権限を付けて（`chmod +x`）起動します。
    対応環境は GNOME の Wayland セッションと X11 です。 それ以外の Wayland コンポジター（KDE
    など）ではアプリは起動しますが、コピー 2 回の合図を受け取れません。
  </TabItem>
</Tabs>

## 2. AI をつなぐ {#connect-an-ai}

ZenCopy を起動しても、ウィンドウはすぐには開きません。
画面の隅にあるアイコン置き場（Windows ならタスクバー右下、Mac なら画面上部のメニューバー）に常駐し、はじめての起動ではようこそ画面が開きます。

## 3. 最初のコピー 2 回 {#first-copy-twice}

<Tabs syncKey="os">
  <TabItem label="Windows">準備はこれで全部です。そのまま試せます。</TabItem>
  <TabItem label="macOS">
    あと 1 つだけ。「コピーが 2 回押された」ことに気づくための許可が必要です。
    **システム設定 → プライバシーとセキュリティ → 入力監視** で ZenCopy
    をオンにして、ZenCopy を一度終了して起動し直してください。
    キー操作の合図に気づくための許可で、画面の内容を読むものではありません。

    {/* 撮影: システム設定 → プライバシーとセキュリティ → 入力監視で ZenCopy がオンになっている画面 */}

    ![入力監視の設定画面で ZenCopy をオンにしたところ](/ja/screenshots/macos-input-monitoring.png)

  </TabItem>
  <TabItem label="Linux">
    GNOME（Wayland）では、検知用の小さな GNOME Shell 拡張が初回起動時に自動インストールされています（sudo
    不要）。 有効にするために、**一度ログアウトして再ログイン**してください。 X11 ではこのまま試せます。
  </TabItem>
</Tabs>

準備ができたら、このページのどこかの段落を選択して、**<span data-os-modifier>Ctrl/⌘</span> + C + C**（コピーをすばやく 2 回）。
画面の隅にポップアップが現れ、要約が流れるように表示されれば完了です。

{/* 撮影: ポップアップに要約の答えが表示され、下の入力欄で会話を続けている状態 */}

![要約の答えに「もう少し詳しく」と返信した会話の画面](/ja/screenshots/popup.png)

あとは好きに触ってください。

- 答えの下の入力欄に返信すると、そのまま会話が続きます。
- 答えの上に並ぶ「要約」「解説」「翻訳」「清書」は切り替えボタンです。数字キー 1 つで押せます。
- 閉じるのは **Esc**。テキストだけでなく、スクリーンショットやファイルも同じ操作で扱えます。

## しくみと安心 {#how-it-works}

<ArchitectureDiagram locale="ja" />

- 普通の 1 回のコピーでは、何も起きません。読み取りも送信もありません。パスワードマネージャーが「機密」と印を付けたコピーは、2 回押しても無視します。
- コピーした内容は、あなたがつないだ AI へ直接送られます。ZenCopy のサーバーというものは存在しません。
- API キーや設定はこのパソコンの中だけに保存され、会話はどこにも残りません。
- AI は流暢に間違えることがあります。大事な数字や固有名詞は、元の文章で確かめてから使ってください。

## 使いこなす {#make-it-yours}

設定画面は、常駐アイコンのメニューか、ポップアップの歯車アイコンから開けます。

### 自分のプロンプトを作る {#create-a-prompt}

設定 → プロンプト → **新しいプロンプト**。
書くのは名前と「やってほしいこと」の 2 つだけです。

{/* 撮影: プロンプトの作成画面。名前と指示の入力欄、「AI で下書き」ボタンが写っていること */}

![プロンプトの作成画面。名前と指示の入力欄](/ja/screenshots/prompt-editor.png)

> 例: 名前「3 行まとめ」、指示「3 行で要約してください」

指示をうまく書く自信がなければ、やりたいことを雑に書いて **AI で下書き**を押してください。
つないだ AI が整った指示に仕上げ、気に入らなければもう一度押すと練り直します。

作ったプロンプトは**エクスポート**でファイルにして人に渡せます。
受け取る側は**インポート**に貼り付けるか、ファイルを選ぶだけです。

### 振り分けを決める {#routing}

コピーの種類ごとに、最初にどのプロンプトが動くかを決められます（初期状態では、テキストは「要約」、画像とファイルは「解説」）。
さらに設定 → プロンプト → **新しいルール**で、条件つきの振り分けも作れます。

{/* 撮影: 新しいルールの作成画面。アプリ名や URL などの条件と、動かすプロンプトの選択が写っていること */}

![新しいルールの作成画面。条件と、動かすプロンプトの選択](/ja/screenshots/new-rule.png)

> 例: 「Slack で 200 文字以上をコピーしたときは、要約を動かす」

条件は上から順に試され、最初に当てはまったルールが勝ちます。

### 別の AI に切り替える {#switch-ai}

設定 → AI タブで、いつでもつなぎ替えられます。

{/* 撮影: 設定画面の AI タブ。プロバイダーの選択、モデル、API キーの欄が写っていること */}

![設定画面の AI タブ](/ja/screenshots/settings-ai.png)

- **ChatGPT や Claude を使いたい**: プロバイダーで OpenAI または Anthropic を選び、その会社の API キーを貼ります。
  ChatGPT Plus などの月額契約に API キーは含まれず、別途発行する従量制です。
  ZenCopy の使い方なら月に数十円から数百円に収まる人がほとんどで、使った量は[利用統計](#appearance-and-behavior)でいつでも確かめられます。
- **何も外に送りたくない**: AI をこのパソコンの中だけで動かします。
  [Ollama](https://ollama.com) を入れてモデルを 1 つダウンロードし、プロバイダーで **OpenAI 互換**を選んで、ベース URL に `http://localhost:11434/v1`、モデル名に Ollama でのモデル名を書きます。
  コピーして使える設定例は[レシピ集](/ja/recipes/)にあります。
- どの方法でも、**テスト**ボタンで今すぐ確かめられます。
  失敗したら見直すのは 4 つだけです: モデル名、API キー、ベース URL、インターネット接続。

AI タブの**あなたについて**欄に、自分の役割や好みを普段の言葉で数行書いておくと、すべてのプロンプトの結果があなた向けに調整されます。

> 例: 「営業職。お客様へのメールが多い。丁寧すぎない敬語で、結論を先に。」

### 見た目とふるまい {#appearance-and-behavior}

設定 → 一般タブにまとまっています。

{/* 撮影: 設定画面の一般タブの全体 */}

![設定画面の一般タブ](/ja/screenshots/settings-general.png)

- **ポップアップの位置**、**文字サイズ**、**テーマ**、**表示言語**、**ログイン時に起動**。
- **利用統計**: 実行のたびにこの端末の中の記録へ 1 行追加し、かかったお金の概算と月の上限はここから計算されます。どこにも送信されません。
- **送信前の確認**: 画像やファイルを AI に送る前に、ひと言たずねるかどうか。
- **初期化**: すべての設定と API キーを消して、最初の状態に戻します。

## 設定ファイル（上級者向け） {#config-files}

画面の設定だけで主要な機能はすべて使えます。
テキストファイルを直接編集したい方だけ読んでください。
ファイルはアプリ設定ディレクトリにあり、編集は次のトリガーから反映されます:

<Tabs syncKey="os">
  <TabItem label="Windows">`%APPDATA%\app.zencopy`</TabItem>
  <TabItem label="macOS">`~/Library/Application Support/app.zencopy`</TabItem>
  <TabItem label="Linux">`~/.config/app.zencopy`</TabItem>
</Tabs>

- **`ai-sdk-catalog.json`**: プロバイダーと role → モデルの対応。設定画面の AI タブが読み書きしているのはこのファイルで、`roles` には必ず `default` を含めます。
  形式の本家は [ai-sdk-catalog](https://github.com/sincekmori/ai-sdk-utils/tree/main/packages/catalog#readme)、ZenCopy 向けの出発点は[レシピ集](/ja/recipes/)です。
- **`rules.json`**: どの種類のキャプチャをどのプロンプトが処理するかの上書き。`kind`（`text` / `image` / `files`）のほか、`app_name`、`url`、`file_name`（`*` ワイルドカード対応）、`min_chars` / `max_chars` を条件にできます。
- **`prompts/*.md`**: 1 ファイル = 1 プロンプト。YAML フロントマター（`id`、`label`、`role`、`instructions`）と [Liquid](https://liquidjs.com) の本文で、このファイルがそのまま共有形式です。
  `{{ text }}` や `{{ url }}`、`{{ app_name }}` などの変数が使えます。実際にどんな値が入るかは、一般タブの**開発者モード**をオンにするとポップアップで確認できます。

## 困ったとき {#troubleshooting}

- **ポップアップが出ない（macOS）**: ほぼ確実に[入力監視の許可](#first-copy-twice)です。オンにして、アプリを起動し直してください。
- **結果が出ない・「時間切れ」と出る**: 応答が 90 秒途絶えると失敗として表示します。インターネット接続と AI の設定を確認して、**やり直す**を押してください。[テストボタン](#switch-ai)でも確かめられます。
- **DeepL など、別のアプリのポップアップも出る**: 「コピー 2 回」を待ち受けるアプリが他にもあると両方反応します。壊れているわけではないので、使う頻度の低い方のショートカットを無効にしてください。
- **トレイアイコンが出ない（Linux）**: 素の GNOME（Fedora など）では **AppIndicator and KStatusNotifierItem Support** 拡張を入れるまで表示されません。アプリ自体は動いています。
- **ログを見たい**: コピーした内容や API キーは残りません。場所は次のとおりです:

<Tabs syncKey="os">
  <TabItem label="Windows">`%LOCALAPPDATA%\app.zencopy\logs`</TabItem>
  <TabItem label="macOS">`~/Library/Logs/app.zencopy/`</TabItem>
  <TabItem label="Linux">`~/.local/share/app.zencopy/logs`</TabItem>
</Tabs>

## アンインストール {#uninstall}

<Tabs syncKey="os">
  <TabItem label="Windows">
    アンインストーラーの「**アプリケーションデータを削除する**」にチェックを入れると、設定、API
    キー、ログまですべて消えます。
  </TabItem>
  <TabItem label="macOS">
    先に**設定 → 初期化**を実行してから（API キーを含む全設定が消えます）、アプリをゴミ箱へ。
    ログだけは診断用に残るので、完全に消すなら `~/Library/Logs/app.zencopy` を手で削除してください。
  </TabItem>
  <TabItem label="Linux">
    先に**設定 → 初期化**を実行してから、パッケージまたは AppImage を削除してください。 GNOME
    のトリガー拡張は `gnome-extensions uninstall copycopy@sincekmori.github.io` で削除できます。
  </TabItem>
</Tabs>
