## 切り替える {#switch-with-number-keys}

答えの上に並ぶ「要約」「解説」「翻訳」「清書」「カスタム」は、<CopyTwice />のあとに AI にする頼みごとの型で、**プロンプト**と呼びます。
クリックか、並び順の数字キーで切り替わります（並び順は設定で変えられます）。

{/* 動画: 解説デモ（bun run demo-video が生成）。要約の答えの画面で「解説」に切り替え、解説が表示されるまで */}

<DemoVideo demo="explain">
  デモ動画を見る
</DemoVideo>

「解説」に切り替えると、同じ文章をやさしい言葉でかみ砕きます。

- **要約**: 一文で要点します。
- **解説**: 前提知識がなくてもわかる言葉で、かみ砕いて解説します。
- **翻訳**: あらゆる言語を日本語に。すでに日本語なら、英語に翻訳します。
- **清書**: 誤字や敬語、言い回しを整えて送れる文に。メールからコピーすればメールらしく、チャットならチャットらしく。
- **カスタム**：入力欄に書いた言葉が、そのまま頼みごとに。

## 続けて頼む {#follow-up}

答えの下の入力欄（「メッセージを入力」）に返信すると、同じ会話が続きます。

{/* 動画: 返信デモ（bun run demo-video が生成）。解説の答えに「もう少し簡潔に」と返信し、短い答えが表示されるまで */}

<DemoVideo demo="follow-up">

「もう少し簡潔に」と返すと、答えが短くなります。
Enter で送信、Shift + Enter で改行です。
変換を確定する Enter では送信されません。
答えごとに「コピー」と「やり直す」のアイコンがついています（重ねると名前が出ます）。

## 自分の言葉で頼む（カスタム） {#custom}

「カスタム」に切り替えると、入力欄が「質問や指示を入力」に変わって待ちます。
「表にして」「この単語の意味は？」「返信の下書きを英語で」のように、コピーしたものへの頼みごとを自分の言葉で書いて、Enter。

## 画像やファイルも同じ操作 {#images-and-files}

エラー画面は、<OsText windows="Win + Shift + S" mac="⌘ + Shift + Control + 4" /> でスクリーンショットを撮ると、撮った画像がコピーされた状態になります。
デスクトップやブラウザなど、何も選んでいない画面でそのまま <CopyTwice />すると、「解説」で返ります。

{/* 要実機確認: コードでは成立（copycopy は 400 ms 待って無条件にクリップボードを読む）。前面アプリの影響（Excel などは選択なしでもコピーする）だけ実機で確認 */}

PDF や Word、Excel、PowerPoint は、<OsText windows="エクスプローラー" mac="Finder" /> でファイルを選んで <CopyTwice />です。
中身がそのまま AI に渡り（1 回 10 MB まで）、こちらも「解説」で返ります。

画像や PDF の送信前には、確認カード「このキャプチャを AI プロバイダーに送信しますか？画像やファイルはテキストより料金がかかることがあります。」が出るので、「送信」を押します。
無料のキーのままなら、ここでも料金は発生しません。

## 閉じる、戻す {#close-and-recall}

答えが流れている間は、入力欄の右端の ■（「停止」）で止めます。
止まったら、Esc か右上の ×（「閉じる」）で閉じます。
入力欄に文字を打っている最中は、1 回目の Esc で欄を抜け、2 回目で閉じます。

閉じた答えは、常駐アイコンのメニューの「アプリを表示」で戻ります。
同じ文章や画像をもう一度 <CopyTwice />しても、AI には送らず、前の答えをそのまま出します（ファイルは中身が変わっているかもしれないので、読み直します）。
別のものを <CopyTwice />した時点で、前の答えは消えます。
残したい答えは、その答えの「コピー」で控えておきます。

ポップアップは上の帯（ZenCopy と書かれた部分）をドラッグで動かせて、端をドラッグすると大きさが変わります。
