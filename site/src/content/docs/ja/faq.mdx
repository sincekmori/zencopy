## お金はかかりますか？ {#does-it-cost-money}

ZenCopy は無料です。
アカウント登録も月額契約もありません。

文章を実際に読んで答える AI の側は、あなたとその AI の契約次第です。
[はじめる](/ja/getting-started/#connect-an-ai)で案内している Google の無料のキーなら、こちらも無料です。
支払い情報を登録しない限り、課金されることはありません。
無料枠の上限に達しても、しばらく使えなくなるだけです。

ChatGPT や Claude の有料の API キーを使う場合は、使った分だけの従量制です。
ChatGPT Plus や Claude Pro の月額契約とは別の契約で、ZenCopy の使い方なら月に数十円から数百円が大半です。
使った分の概算は、設定画面の「一般」タブの「利用統計」で「ポップアップに今月のコストを表示」をオンにするとポップアップに出て、「月のコスト上限 (USD)」も決めておけます。

ZenCopy 自体は、プログラムの中身を誰でも読める形で公開している「オープンソース」のソフトウェアです。
Apache-2.0 という配布条件で、誰でも無料で使えます。

## コピーした内容はどこへ送られる？ {#where-does-my-copied-content-go}

送られるのは <CopyTwice /> のときだけです。今コピーしたものが、あなたが設定した AI（最初は Google の AI）へ直接送られます。
送り先はそこだけです。 ZenCopy 自身のサーバーはなく、中継も、利用状況の収集もありません。 API
キーは、このパソコンの設定ファイルに保存され、その AI
に本人確認として送る以外、どこにも送られません。
何を送ったかは、ポップアップ上部の「コピーした内容」にそのまま表示されます。

Google の無料枠では、送った内容が Google のサービス改善に使われることがあります。
公開されている記事や製品資料、自分の下書き、エラー画面なら、無料枠のままで問題ありません。
顧客名、契約書、未公開の数字が入るものは、会社のルールに従い、無料枠には送らないでください。
仕事で本格的に使うなら、有料の API キーに切り替えます（[設定の「ChatGPT や Claude の API キーを持っている」](/ja/configuration/#bring-a-paid-key)）。

## 会社のパソコンに入れていい？ 情シスに何と言えばいい？ {#is-it-ok-on-a-work-pc}

会社のルールが先です。
アプリの導入に確認や申請が要る会社なら、次の 5 つをそのまま見せてください。

- ZenCopy は無料のオープンソースソフトウェア（Apache-2.0）で、プログラムの中身はすべて公開されています。
- ZenCopy 自身のサーバーはなく、アカウント登録も、利用状況の収集もありません。コピーした内容は、利用者が自分で設定した AI（既定では Google の Gemini）にだけ直接送られます。ほかの通信は、新しいバージョンが出ていないかを配布元（GitHub）に確かめ、あればダウンロードするものだけです。設定画面の「テスト」と「AI で下書き」も、同じ AI にだけ送ります。
- 送られるのは、<OsText windows="Ctrl" mac="⌘" /> を押したまま C を 2 回押したときに、そのときコピーしたものだけです。
- API キーと設定は、そのパソコンの中の設定ファイルに保存されます。ログにコピーした内容や API キーは残りません。
- アンインストールすれば元通りです（[アンインストールすると何が消える？](#what-does-uninstalling-remove)）。

送った内容の扱い（無料枠では Google のサービス改善に使われうること）は、[コピーした内容はどこへ送られる？](#where-does-my-copied-content-go)のとおりです。
確かめたい人向けに、[プライバシー](/ja/privacy/)のページに詳しい説明があります。

## AI の答えはどこまで信頼できる？ {#how-much-can-i-trust-the-ais-answers}

AI は、流暢に間違えることがあります。
要約や解説で大筋をつかむには十分役立ちますが、数字、固有名詞、契約や医療のような重要な内容は、元の文章で確かめてから使ってください。
外国語の資料の要約が本当かを確かめるなら、数字キー 3 の「翻訳」で全文を<PageLanguage />にできます。

## ChatGPT などのチャットサイトと何が違う？ {#how-is-this-different-from-chat-sites-like-chatgpt}

チャットサイトは、ブラウザで開いて、貼り付けて、頼む場所です。
ZenCopy は、今見ているものの上に答えを出します。
選んで <CopyTwice />。
読んでいた文章も、エラー画面のスクリーンショットも、受け取った PDF も、貼り付けなしでそのまま出発点になります。
最初の答え（要約や解説）は自動で始まり、続きは普通のチャットと同じです。
「カスタム」を選べば、最初から自分の言葉で頼めます。
答えるのは、あなたが設定した AI（最初は Google の無料の AI）です。
会話の履歴を ZenCopy はどこにも保存せず、次に別のものをコピーするまでの、その場限りです。
送り先の AI での扱いは、[コピーした内容はどこへ送られる？](#where-does-my-copied-content-go)のとおりです。

## ポップアップが出ない {#the-popup-never-appears-macos}

常駐アイコン（<OsText windows="タスクバー右下" mac="画面上部のメニューバー右側" />）が見当たらなければ、ZenCopy は起動していません。
「ログイン時に起動」は最初はオフなので、パソコンを再起動したあとは待機していません。

もう一度使うには、<OsText windows="スタートメニュー" mac="Launchpad" />から起動するか、設定画面の「一般」タブで「ログイン時に起動」をオンにしてください。

合図は、<OsText windows="Ctrl" mac="⌘" /> を押したまま、C をダブルクリックの要領で 2 回です。

途中で <OsText windows="Ctrl" mac="⌘" /> を離してからもう一度コピーしたり、間が空いたりすると、合図になりません。

Mac で、ようこそ画面ではキーの欄の上に、設定画面ではタブの上に、黄色い通知「あと一歩です。コピーの 2 連打を検知するには macOS の許可が必要です。…」が出ていれば、「入力監視」の許可がまだです。

1. 「システム設定」→「プライバシーとセキュリティ」→「入力監視」で、ZenCopy を許可します。
2. 常駐アイコン（画面上部のメニューバー右側）のメニューから「終了」を選びます。
3. Launchpad から ZenCopy を開き直します。黄色い通知が消えていれば完了です。

この許可は、C が 2 回押されたことに気づくためのもので、画面の内容を読むものではありません。

## 「モデルから応答がありませんでした」と出る {#no-result-comes-back--it-says-it-timed-out}

AI からの答えが 90 秒届かないと、ZenCopy は待つのをやめて「モデルから応答がありませんでした。ネットワークとプロバイダー設定を確認して、やり直してください。」と表示します。
インターネットにつながっているかを確かめて、「やり直す」を押してください。
それでも続くなら、設定画面の「AI」タブで「テスト」を押し、「接続できました」が出るかを確かめます（[設定の「接続を確かめる」](/ja/configuration/#test-the-connection)）。

「失敗しました: …」と出たときは、そのあとに AI 側から返った理由がそのまま続きます（英語のこともあります）。
API キーが間違っているときや、無料枠の上限に達したときも、この形で出ます。
無料枠の上限なら、しばらく待つとまた使えます。

{/* 形はコードで確定（onError → 失敗しました: …）。Google の理由文の実例だけ、無料枠を使い切ったキーで確認 */}

「今月のコスト上限(…)に達しました。設定から変更できます。」は、自分で決めた月の上限に今月の概算が届いたときの表示です。
設定画面の「一般」タブの「利用統計」にある「月のコスト上限 (USD)」を上げるか空欄にすると、また使えます。

## ログはどこ？ {#where-are-the-logs}

常駐アイコン（<OsText windows="タスクバー右下" mac="画面上部のメニューバー右側" />）のメニューから「ZenCopy について」を開き、「ログ」を押すと、ログのフォルダが開きます。
サポートに送るときは、いちばん新しいファイルを添付してください。
ログにコピーした内容や API キーは残りません。

フォルダの場所そのものは次のとおりです。

  <TabItem label="Linux">`~/.local/share/app.zencopy/logs`</TabItem>

## アンインストールすると何が消える？ {#what-does-uninstalling-remove}

<Tabs syncKey="os">
  <TabItem label="Windows">
    Windows の「設定」→「アプリ」から ZenCopy をアンインストールします。

    途中で、アプリのデータも削除するかを聞かれます。

    チェックを入れると、設定、API キー、自作のプロンプト、ログまで、すべて消えて元通りです。

  </TabItem>
  <TabItem label="macOS">
    アプリをゴミ箱に入れても、データは残ります（macOS の流儀で、ZenCopy もそれに従います）。

    すべて消すには、先に設定画面の「一般」タブで「初期化」を実行してから、アプリをゴミ箱へ入れます。

    ログだけは診断用に残るので、それも消すなら `~/Library/Logs/app.zencopy` を手で削除します。

  </TabItem>
  <TabItem label="Linux">
    パッケージマネージャーが消すのはアプリ本体だけで、データは残ります（これも Linux の流儀です）。

    すべて消すには、先に設定画面の「一般」タブで「初期化」を実行してから、パッケージまたは AppImage を削除します。

    GNOME の拡張は `gnome-extensions uninstall copycopy@sincekmori.github.io` で削除できます。

  </TabItem>
</Tabs>

## 対応している Linux 環境は？ {#which-linux-environments-are-supported}

GNOME の Wayland セッションと、X11 です。
GNOME の Wayland では、背後で動くプロセスがキー入力やクリップボードを見ることが設計上できないため、ZenCopy は小さな GNOME Shell 拡張を同梱し、コンポジターの内側で「<CopyTwice />」を検知します。
拡張は初回起動時にユーザーのプロファイルへ自動で入り（sudo は不要）、一度ログアウトしてログインし直すと有効になります。
X11 では、Windows と同じく、通常のキー監視で動きます。
それ以外の Wayland コンポジター（KDE Plasma、wlroots 系）には、特権なしで合図を検知する手段がなく、今のところ非対応です。
アプリ自体は起動しますが、合図に反応しません。

## 常駐アイコンが表示されない（Linux） {#the-tray-icon-does-not-show-up-linux}

Linux の常駐アイコンは、AppIndicator という仕組みで表示されます。
Ubuntu の GNOME は標準で対応していますが、素の GNOME（Fedora など）では「AppIndicator and KStatusNotifierItem Support」という Shell 拡張を入れるまで表示されません。
どちらの場合もアプリ自体は動いていて、アイコンのメニューは呼び出し口の 1 つにすぎません。
設定画面は、ポップアップ右上の歯車（「設定を開く」）からも開けます。

## 他の「選択テキスト + AI」系ツールと何が違う？ {#how-is-this-different-from-other-ai-on-selection-tools}

この分野のツールの多くは Mac 専用で、扱えるのは選択したテキストだけ、AI は特定のサービスや月額契約に固定されています。
ZenCopy は Windows、macOS、Linux で動き、テキスト、画像、ファイルを扱え、AI は自分で選べます。
無料の Google の AI で始めて、OpenAI や Anthropic の有料の API キーや、[自分のパソコンの中だけで動く AI](/ja/recipes/#run-a-local-ai) に切り替えられます。
一往復では終わらず、答えの下の入力欄からその場で会話を続けられます。
コピーの種類ごとに最初にどのプロンプトを使うかも、[自分で決められます](/ja/configuration/#routing-rules)。
アカウントも月額契約も利用状況の収集もない、オープンソースのソフトウェアです。
