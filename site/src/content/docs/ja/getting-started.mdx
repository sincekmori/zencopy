## 要約のほかにできること {#what-you-can-do}

同じ <CopyTwice />のまま、頼みごとを切り替えるだけで、別の答えが出ます。

- 意味のわからないエラー画面：スクリーンショットを <CopyTwice />。**解説**が、やさしい言葉でかみ砕きます。
- 外国語の資料：**翻訳**で全文を<PageLanguage />に。自分で書いた<PageLanguage />の下書きなら、英語に。
- 雑に書いた下書き：**清書**が、誤字や言い回しを直して送れる敬語にします。
- 「表にして」「気をつける点は？」：**カスタム**で、コピーしたものへの頼みごとを自分の言葉で。
- PDF や Word のファイルも、選んで <CopyTwice />。

相手が何語でも、<PageLanguage />で返ってきます。

## 安心して使うために {#before-you-start}

ZenCopy は無料です。

あなたが設定した AI へ直接送られるのは、<CopyTwice /> したものだけです。 ZenCopy
側にサーバーはなく、作者にも届きません。
何を送ったかは、ポップアップ（画面の隅に開く小さな窓）の上部の「コピーした内容」の欄で確かめられます。

入れたあとの ZenCopy は、ふだん画面に何も出しません。
常駐アイコン（<OsText windows="タスクバー右下" mac="画面上部のメニューバー右側" />）になって、<CopyTwice />を待っている小さなアプリです。
やめたくなったら、アンインストールで元通りになります。

情シスに聞かれたときの説明は、FAQ の[「会社のパソコンに入れていい？」](/ja/faq/#is-it-ok-on-a-work-pc)にまとめました。

## 2. AI の設定 {#connect-an-ai}

ZenCopy には、答えを作る AI をつなぎます。
Google の AI（Gemini）なら無料で始められるので、この節はその手順です。

ZenCopy が起動すると、ようこそ画面が開きます。
開いていなければ、<OsText windows="スタートメニュー" mac="Launchpad" /> から ZenCopy を起動します。

![ようこそ画面。「Gemini API キー」の欄と「このキーではじめる」ボタン](/ja/screenshots/welcome.png)

ここに貼るのは、Google の AI を使うための **API キー**、つまりあなた専用の鍵です。
Google アカウントがあれば無料で作れて、会社のアカウントでも個人のアカウントでもかまいません。
パスワードと同じ扱いで、人に送りません。
貼ったキーはこのパソコンの中にだけ保存され、ZenCopy 側に届くことはありません。
支払い情報を登録しない限り、課金されることはありません。

<Steps>

1. [Google AI Studio の API キーのページ](https://aistudio.google.com/api-keys)を、Google アカウントで開きます。
   会社の Google アカウントで開けないときは、個人のアカウントで開きます。

2. 「API キーを作成」を押します。

   {/* 撮影: Google AI Studio の API キーのページ。「API キーを作成」ボタンが写っていること（ログイン済み状態）。要確認: ボタンの日本語表記（英語 UI では Create API key）。撮影時に本文の名前を合わせる */}

   {/* 撮影後に有効化: ![Google AI Studio の API キーのページ。「API キーを作成」ボタン](/ja/screenshots/aistudio-create-key.png) */}

3. 表示された `AIza…` で始まる文字列をコピーして、ようこそ画面の「Gemini API キー」の欄に貼り、「このキーではじめる」を押します。

</Steps>

つながると、同じウィンドウが設定画面に変わります。
ここでは何も触らずに閉じてかまいません。

無料のキーには、送った内容が Google のサービス改善に使われることがある、という条件がつきます。
公開されている記事や製品資料、自分の下書き、エラー画面なら、そのままで大丈夫です。
顧客名、契約書、未公開の数字が入るものは、会社のルールに従い、送りません。
無料枠の上限に達しても、しばらく使えなくなるだけです。

欄が赤くなって「接続できませんでした。モデル名・API キー・ベース URL・ネットワークを確認してください。」と出たら、たいていはキーの貼り漏れ（`AIza…` を最初から最後まで）か、インターネットにつながっていないかのどちらかです。
キーを貼り直すか、接続を確かめてから、もう一度「このキーではじめる」を押します。

ChatGPT や Claude の API キーを持っている人や、仕事の資料で本格的に使う人は、あとから設定画面の[「ChatGPT や Claude の API キーを持っている」](/ja/configuration/#bring-a-paid-key)で有料の AI に切り替えられます。

## 答えのあとにできること {#after-the-answer}

### 切り替える {#switch-with-number-keys}

答えの上に並ぶ「要約」「解説」「翻訳」「清書」「カスタム」は、<CopyTwice />のあとに AI にする頼みごとの型で、**プロンプト**と呼びます。
クリックか、並び順の数字キーで切り替わります（並び順は設定で変えられます）。

{/* 動画: 解説デモ（bun run demo-video が生成）。要約の答えの画面で「解説」に切り替え、解説が表示されるまで */}

「解説」に切り替えると、同じ文章をやさしい言葉でかみ砕きます。

<DemoVideo demo="explain">
  デモ動画を見る
</DemoVideo>

- **要約**：一文で要点。
- **解説**：前提知識がなくてもわかる言葉で、かみ砕いて。
- **翻訳**：<PageLanguage />に。すでに<PageLanguage />なら、英語に。
- **清書**：同じ言語のまま、誤字や敬語、言い回しを整えて送れる文に。メールからコピーすればメールらしく、チャットならチャットらしく。翻訳はしません。
- **カスタム**：入力欄に書いた言葉が、そのまま頼みごとに。

### 続けて頼む {#follow-up}

答えの下の入力欄（「メッセージを入力」）に返信すると、同じ会話が続きます。

{/* 動画: 返信デモ（bun run demo-video が生成）。解説の答えに「もう少し簡潔に」と返信し、短い答えが表示されるまで */}

「もう少し簡潔に」と返すと、答えが短くなります。

<DemoVideo demo="follow-up">
  デモ動画を見る
</DemoVideo>

Enter で送信、Shift + Enter で改行です。
変換を確定する Enter では送信されません。
答えごとに「コピー」と「やり直す」のアイコンがついています（重ねると名前が出ます）。

### 自分の言葉で頼む（カスタム） {#custom}

「カスタム」に切り替えると、入力欄が「質問や指示を入力」に変わって待ちます。
「表にして」「この単語の意味は？」「返信の下書きを英語で」のように、コピーしたものへの頼みごとを自分の言葉で書いて、Enter。

### 画像やファイルも同じ操作 {#images-and-files}

エラー画面は、<OsText windows="Win + Shift + S" mac="⌘ + Shift + Control + 4" /> でスクリーンショットを撮ると、撮った画像がコピーされた状態になります。
デスクトップやブラウザなど、何も選んでいない画面でそのまま <CopyTwice />すると、「解説」で返ります。

{/* 要実機確認: コードでは成立（copycopy は 400 ms 待って無条件にクリップボードを読む）。前面アプリの影響（Excel などは選択なしでもコピーする）だけ実機で確認 */}

PDF や Word、Excel、PowerPoint は、<OsText windows="エクスプローラー" mac="Finder" /> でファイルを選んで <CopyTwice />です。
中身がそのまま AI に渡り（1 回 10 MB まで）、こちらも「解説」で返ります。

画像や PDF の送信前には、確認カード「このキャプチャを AI プロバイダーに送信しますか？画像やファイルはテキストより料金がかかることがあります。」が出るので、「送信」を押します。
無料のキーのままなら、ここでも料金は発生しません。

### 閉じる、戻す {#close-and-recall}

答えが流れている間は、入力欄の右端の ■（「停止」）で止めます。
止まったら、Esc か右上の ×（「閉じる」）で閉じます。
入力欄に文字を打っている最中は、1 回目の Esc で欄を抜け、2 回目で閉じます。

閉じた答えは、常駐アイコンのメニューの「アプリを表示」で戻ります。
同じ文章や画像をもう一度 <CopyTwice />しても、AI には送らず、前の答えをそのまま出します（ファイルは中身が変わっているかもしれないので、読み直します）。
別のものを <CopyTwice />した時点で、前の答えは消えます。
残したい答えは、その答えの「コピー」で控えておきます。

ポップアップは上の帯（ZenCopy と書かれた部分）をドラッグで動かせて、端をドラッグすると大きさが変わります。

## 毎日使うために {#next}

パソコンを再起動したあとは、ZenCopy を起動し直すまで、<CopyTwice />に反応しません。

<OsText windows="スタートメニュー" mac="Launchpad" /> から起動します。 設定 → 一般 →
「ログイン時に起動」をオンにしておけば、毎朝そのまま使えます。

30 秒で効く設定が 1 つあります。
設定の「あなたについて」に、役割と好みを一行書いておくと、すべての頼みごとに添えられ、答えがあなた向けに寄ります。
たとえば「営業職。お客様へのメールが多い。丁寧すぎない敬語で、結論を先に。」（[設定 → あなたについて](/ja/configuration/#about-you)）。

別の AI に切り替えたくなったら[設定](/ja/configuration/)へ、困ったら [FAQ](/ja/faq/) へ。

次に読めないメールが来たら、選んで <CopyTwice />。
