AI はどんどん賢くなっていきますが、それを使う私たち人間の負荷は、以前として高いままです。

## ZenCopy でできること {#what-you-can-do}

メールの要約は、ZenCopy の可能性を実感していただくためのほんの入り口に過ぎません。
実際には、長いチャットのやりとりやオンライン会議の共有画面、さらには配布された pptx ファイルなど、あらゆる対象を要約できます。
しかも、できることは要約だけにとどまりません。
解説や翻訳、清書といった基本的なタスクはもちろん、あなたが思い描くあらゆる処理を自由に設定して実行することができます。

<Diagram name="overview" alt="メール、チャット、画面、ファイル、そのほかコピーできるもの何でもから、ZenCopy が要約、解説、翻訳、清書、そしてカスタム（何でも）の答えを返す図" />

つまり、ZenCopy は、コピーできるすべてのものを対象にして、自由自在に AI 処理ができるアプリなのです。
これほど強力な機能を使うために覚える操作はたった一つ、<CopyTwice /> だけです。

## 安心してご利用いただくために {#before-you-start}

ZenCopy は商用・非商用を問わず無償でご利用いただけます。
ソースコードは Apache-2.0 ライセンスで[公開されています](https://github.com/sincekmori/zencopy)。

AI には無料の Gemini を使うことができるし、あなたが契約している他のどんな AI を設定してもらってもいいです。
もちろんローカル LLM を設定することもできます。

コピーされたデータが送信されるのは、あなたが設定した AI のみです。
ZenCopy にサーバーはなく、ログにも残りません。

消したくなったら他のアプリと同様にアンインストールすれば良いです。

:::note[ZenCopy にテレメトリーはありません]

一般に、こういったアプリはユーザーの操作記録を外部サーバーに送信することが多いです。
改善のために統計情報として収集するのです。
この機能をテレメトリーといいます。
私（ZenCopy の作者）は、このようなユーザーに隠れてこそこそ外部にデータを送信する機能が大嫌いです。
しかもこの機能はデフォルトで有効になっていることが多いです。
本当にクソったれです。

ZenCopy はユーザーにテレメトリーの有効/無効を選択させるのではなく、そもそもテレメトリーの機能を実装していません。
未来永劫実装することもありません。
そのようなプルリクエストが届いてもすべて拒否します。

:::

## AI の設定 {#connect-an-ai}

要約や解説といった処理をするには AI が必要です。
その設定をします。
ZenCopy は無料枠で十分使える Gemini をデフォルトの AI として採用しています。
それ以外の AI をご利用になる場合は[「ChatGPT や Claude の API キーを持っている」](/ja/configuration/#bring-a-paid-key)をご覧ください。

<Screenshot name="welcome" alt="ようこそ画面。「Gemini API キー」の欄と「このキーではじめる」ボタン" />

すでに Gemini の API キーをお持ちの方は画面に入力し、「このキーではじめる」を押すと ZenCopy を使い始めることができます。
まだお持ちでない方は、以下の手順で無料で取得することができます。

<Steps>

1. [Google AI Studio の API キーのページ](https://aistudio.google.com/api-keys)を開きます。

2. 初めて開くと「AI Studio へようこそ」の画面が出ます。

   <Capture name="aistudio-welcome" alt="「AI Studio へようこそ」の画面。「契約」の 1 つ目にチェックが入り、右下に「続行」のボタン" />

   同意したら「契約」の 1 つ目にチェックを入れて、「続行」を押します。
   2 つ目のメールの受け取りは、入れなくてもかまいません。

3. 少し待つと API キーが自動で発行され、一覧に表示されます。

   <Capture name="aistudio-api-keys" alt="「API キー」のページ。一覧に Default Gemini API Key の行があり、その右にコピーのボタン。右上に「API キーを作成」のボタン" />

   「請求階層」の列が「無料枠」となっていることを確認し、右にあるコピーのボタンを押してください。
   すると、あなた個人の Gemini API キーがコピーされます。
   もし一覧に表示されなければ、右上の「API キーを作成」から簡単に発行することができます。

4. 取得したキーを「ZenCopy へようこそ」に入力し、「このキーではじめる」を押してください。

</Steps>

## あなたを邪魔しないために {#next}

<Philosophy />

これは ZenCopy が目指している思想です。
画面に居座らず、<CopyTwice />のときだけ現れて、用が済んだら引っ込みます。
ZenCopy が占有するメモリは Windows ならたったの 8 MB です。
決してあなたの作業を邪魔せず、軽快に動作します。

しかし、この思想を実現するには、もう一つだけあなたの作業が必要です。
今のままだと、パソコンを立ち上げるたびに ZenCopy を起動し直す必要があります。
次の設定で、その手間がなくなります。

ポップアップの右上にある <Icon name="settings" /> を押すと、設定画面が開きます。

<Screenshot name="settings-autostart" alt="設定画面。上に AI、プロンプト、一般のタブが並び、一般のタブにポップアップの表示位置の選択と、オンになった「ログイン時に起動」のスイッチ" />

上のタブで「一般」を選び、「ログイン時に起動」をオンにします。
このとき、パソコンから「バックグラウンド項目が追加されました」といった通知が出ることがありますが、そのままで大丈夫です。

これで、次からは ZenCopy が自動で起動します。
