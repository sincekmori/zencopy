長い記事、外国語のチャット、意味のわからないエラー画面。
読んでいるものを選んで、いつものコピーをすばやく 2 回。
それだけで、今見ている画面の隅に AI の答えが現れます。
どう頼むかを考える必要はありません。
要約か、翻訳か、答えか — コピーした内容を見て AI が判断します。
ZenCopy は、そのための無料アプリです。

やることは 3 つ、インストール、AI をつなぐ、コピー 2 回。
全部で 10 分です。

## 2. AI をつなぐ {#connect-an-ai}

ZenCopy を起動しても、ウィンドウはすぐには開きません。
画面の隅にあるアイコン置き場（Windows ならタスクバー右下、Mac なら画面上部のメニューバー）に常駐し、はじめての起動ではようこそ画面が開きます。

{/* 撮影: ようこそ画面の全体。API キーの入力欄と「このキーではじめる」ボタン、下部の「別の方法で設定する」リンクが写っていること */}

![ようこそ画面。API キーの入力欄と「このキーではじめる」ボタン](/ja/screenshots/welcome.png)

ここで、要約や翻訳を実際に行う AI をつなぎます。
あてはまる方を選んでください。

<Tabs>

    2. 「**API キーを作成**」（Create API key）ボタンを押します。

    3. 表示された長い文字列（`AIza…` で始まる、AI を使うための鍵にあたる文字列です）をコピーして、ようこそ画面に貼り付け、**このキーではじめる**を押します。

    </Steps>

    「勝手に課金されないだろうか」と不安になるかもしれません。
    なりません。

    1 つだけ注意があります。無料枠では、送った内容が Google のサービス改善に使われることがあります。

## 3. 最初のコピー 2 回 {#first-copy-twice}

<Tabs syncKey="os">
  <TabItem label="Windows">準備はこれで全部です。そのまま試せます。</TabItem>
  <TabItem label="macOS">
    あと 1 つだけ。「コピーが 2 回押された」ことに気づくための許可が必要です。
    **システム設定 → プライバシーとセキュリティ → 入力監視** で ZenCopy
    をオンにして、ZenCopy を一度終了して起動し直してください。
    キー操作の合図に気づくための許可で、画面の内容を読むものではありません。

    {/* 撮影: システム設定 → プライバシーとセキュリティ → 入力監視で ZenCopy がオンになっている画面 */}

    {/* 撮影後に有効化: ![入力監視の設定画面で ZenCopy をオンにしたところ](/ja/screenshots/macos-input-monitoring.png) */}

  </TabItem>
  <TabItem label="Linux">
    GNOME（Wayland）では、検知用の小さな GNOME Shell 拡張が初回起動時に自動インストールされています（sudo
    不要）。 有効にするために、**一度ログアウトして再ログイン**してください。 X11 ではこのまま試せます。
  </TabItem>
</Tabs>

準備ができたら、このページのどこかの段落を選択して、**<span data-os-modifier>Ctrl/⌘</span> + C + C**（コピーをすばやく 2 回）。
画面の隅にポップアップが現れ、答えが流れるように表示されれば完了です。
何が返るかは内容しだいです。外国語なら翻訳、長い文章なら要約、問題なら答え。
狙いと違ったら、下の入力欄でそのまま注文を付ければ直ります。

{/* 撮影: ポップアップに要約の答えが表示され、下の入力欄で会話を続けている状態（現行の popup.png を流用可） */}

![要約の答えに「もう少し詳しく」と返信した会話の画面](/ja/screenshots/popup.png)

あとは好きに触ってください。

- 答えの下の入力欄に返信すると、そのまま会話が続きます。
- 答えの上に並ぶ「自動」「要約」「解説」「翻訳」「清書」は切り替えボタンです。数字キー 1〜5 で押せます。
- 閉じるのは **Esc**。テキストだけでなく、スクリーンショットやファイルも同じ操作で扱えます。

## しくみと安心 {#how-it-works}

<ArchitectureDiagram locale="ja" />

- 普通の 1 回のコピーでは、何も起きません。読み取りも送信もありません。
- コピーした内容は、あなたがつないだ AI へ直接送られます。ZenCopy のサーバーというものは存在しません。
- API キーや設定はこのパソコンの中だけに保存され、会話はどこにも残りません。
