長い記事、外国語のチャット、意味のわからないエラー画面。
「AI に聞けば早いんだろうな」とは思うものの、チャットのサイトを開いて、貼り付けて、と考えると腰が重くなり、結局そのまま読み飛ばす。
心当たりがあるなら、ZenCopy はそのための道具です。

読んでいた部分を選んで、いつものコピーをすばやく 2 回。
それだけで、今見ている画面の隅に AI の答えが現れます。

## しくみ {#how-it-works}

<ArchitectureDiagram locale="ja" />

新しい操作は覚えません。
合図は、誰もが知っているコピーを、すばやく 2 回続けることです。

ZenCopy は普段、画面の隅のアイコンとして静かに待機しています。
合図を受け取ると、コピーした内容（文章でも、画像でも、ファイルでも）を、あなたが選んだ AI に渡します。
答えは小さなポップアップに流れ、その下の入力欄からそのまま会話を続けられます。

![要約の答えに「もう少し詳しく」と返信した会話の画面](/ja/screenshots/popup.png)

裏返すと、普通の 1 回のコピーでは何も起きません。
読み取りも送信もなく、パスワードマネージャーなどが「機密」と印を付けたコピーは、2 回押しても無視します。
送り先はあなたが選んだ AI だけで、ZenCopy 自身のサーバーというものは存在しません。

このページの残りは、これをあなたのパソコンで動かすまでの道のりです。
やることは 3 つ、インストール、無料の AI キーの用意、貼り付け。
途中に「API キー」という聞き慣れない言葉が 1 つだけ出てきますが、やることは「あるページでボタンを押して、出てきた文字列を貼り付ける」だけです。

## 準備するもの {#what-you-need}

1. **パソコン**：Windows、macOS、Linux で動きます
   （Linux の対応範囲は [FAQ](/ja/faq/#which-linux-environments-are-supported) を参照）。
2. **Google アカウント**：文章を処理する AI を無料で使うために必要です。

なお、会社から AI の設定（JSON と呼ばれるテキストやファイル）を渡されている場合、準備するものは何もありません。
インストールが済んだら、AI キーの節は飛ばして[会社から設定を渡されている場合](#company-issued-config)だけ読んでください。

## 無料の AI キーを用意する {#prepare-a-free-ai-key}

ZenCopy 本体は無料のオープンソースソフトウェアで、アカウント登録もサブスクリプションもありません。
ただし、要約や翻訳を実際に行うのは、しくみの図の右側にいた AI です。
Gemini や ChatGPT として普段目にしているものと、同じ種類の AI です。
その AI を自分のアプリから使うための鍵にあたるのが **API キー**という長い文字列で、家の鍵と同じく**自分専用、他人には見せない**。覚えておくことはそれだけです。

一番簡単なのは Google の無料キーです:

<Steps>

1. [Google AI Studio の API キーのページ](https://aistudio.google.com/api-keys)を開き、Google アカウントでログインします。

2. 「**API キーを作成**」（Create API key）ボタンを押します。

3. 表示された長い文字列（`AIza…` で始まります）をコピーします。
   これがあなたの API キーです。

</Steps>

「勝手に課金されないだろうか」と不安になるかもしれません。
なりません。
個人利用なら無料枠で十分で、**支払い情報を登録しない限り、料金が発生することはありません**。
無料枠の上限に達した場合も、請求が来るのではなく、しばらく使えなくなるだけです。

1 つだけ知っておいてほしいことがあります。
**Google の無料枠では、送った内容がサービス改善のために使われることがあります**（Google の規約によります）。
仕事の機密文書などを扱う場合は、有料設定にするか、[別の AI やローカル実行](/ja/configuration/#ai)を選んでください。

## 会社から設定を渡されている場合 {#company-issued-config}

情報システム部門などから「この設定を使ってください」と JSON を渡されているなら、API キーを作る必要も、Google アカウントも要りません。

はじめての起動で開くようこそ画面で、**別の方法で設定する**を選びます。
開いた設定画面で、プロバイダーの選択肢から **JSON** を選び、渡されたテキストを丸ごと貼り付けて、**保存**、続けて**テスト**を押します。
「接続できました」と出れば完了です（うまくいかないときの見方は[設定の該当節](/ja/configuration/#use-a-company-issued-config)にあります）。

あとの道のりは同じです。
[権限について](#about-permissions)から続けてください。

## 初回起動 {#first-launch}

ZenCopy を起動しても、ウィンドウはすぐには開きません。
画面の隅にあるアイコン置き場（Windows ならタスクバー右下、Mac なら画面上部のメニューバー）に、小さなアイコンとして常駐します。

はじめての起動では、ようこそ画面が開きます。

![ようこそ画面。API キーの入力欄と「このキーではじめる」ボタン](/ja/screenshots/welcome.png)

さきほどコピーした API キーを貼り付けて、**このキーではじめる**を押してください。
セットアップはこれで完了です。

ChatGPT や Claude の有料契約がある、何も外に送りたくない。
そんな場合は Google 以外の AI も選べます（[設定の AI の節](/ja/configuration/#ai)）。

### 権限について {#about-permissions}

<Tabs syncKey="os">
  <TabItem label="Windows">特別な設定は不要です。起動した直後から使えます。</TabItem>
  <TabItem label="macOS">
    macOS では「コピーが 2 回押された」ことにアプリが気づくために、1 つの許可が必要です:

    - **システム設定 → プライバシーとセキュリティ → 入力監視** で ZenCopy をオン

    これはキー操作の**合図に気づくため**の許可で、画面の内容を勝手に読むためのものではありません。
    オンにしたら、ZenCopy を一度終了して起動し直してください。

  </TabItem>
  <TabItem label="Linux">
    許可の操作は不要です。
    GNOME（Wayland）では、初回起動時に小さな GNOME Shell 拡張がユーザープロファイル（`~/.local/share/gnome-shell/extensions/`、sudo 不要）へ自動インストールされます。
    「2 回コピー」を検知できるのはコンポジターの内側だけだからです。
    GNOME が新しい拡張を読み込むのはログイン時なので、初回起動後に**一度ログアウトして再ログイン**してください。
    有効になるまでは、ようこそ画面と設定画面に案内が表示され続けます。
    X11 では起動した直後から使えます。
  </TabItem>
</Tabs>

## 試してみる {#try-it}

道のりの最後は、最初の「コピー 2 回」です。
このページのどこかの段落を選択して、**<span data-os-modifier>Ctrl/⌘</span> + C + C**（コピーをすばやく 2 回）。
画面の隅にポップアップが現れ、要約が流れるように表示されれば成功です。

答えが出たら、少しだけ触ってみてください。

- 答えの上に並ぶ「要約」「解説」「翻訳」「清書」は切り替えボタンです。
  クリックか数字キー 1 つで、同じコピー内容を別のプロンプトで処理し直せます。
- 答えの下の入力欄に「もっと詳しく」と返すと、そのまま会話が続きます。
- 閉じるのは **Esc**。閉じた結果は、常駐アイコンのメニューの「**アプリを表示**」で呼び戻せます。

**2** を押して「解説」に切り替わる様子:
