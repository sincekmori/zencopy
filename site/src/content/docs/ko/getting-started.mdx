ZenCopy는 어떤 앱 위에서든 AI와의 대화를 불러낼 수 있는 도구입니다.
복사할 줄 안다면 쓸 수 있습니다.
배울 것은 딱 하나 — **평소처럼 복사를 빠르게 두 번 하는 것**뿐입니다.
그것만으로 방금 선택한 것에 대한 AI의 답이 화면 구석에 나타나고, **그 아래 입력란에서 그대로 대화를 이어 갈 수 있습니다**.
어떤 앱 위에서든 똑같이 동작합니다.

## ZenCopy가 매일 해 주는 일 {#what-zencopy-does-for-you-every-day}

- 긴 보고서나 기사를 선택하면 **핵심만 몇 줄로** 정리
- 외국어 페이지나 채팅을 **그 자리에서 내 언어로** 변환
- 낯선 용어, 오류 화면, 계약서 문구를 **쉬운 말로 설명**
- 이메일이나 글의 초안을 건네면 **깔끔하게 정리**
- 그리고 답에 이어서 **"더 자세히", "표로 만들어 줘", "그러니까 무슨 뜻이야?"** — 묻고 싶은 만큼 묻기

순서는 언제나 같습니다. 선택하고, 두 번 복사하기.
채팅 사이트를 열 필요도, 붙여넣을 곳을 찾을 필요도 없습니다.
**AI에게 묻고 싶어지면, 일단 복사 두 번** — 그것이 ZenCopy 사용법의 전부입니다.

## 필요한 것 {#what-you-need}

1. **컴퓨터** — ZenCopy는 Windows, macOS, Linux에서 동작합니다.
   (지원되는 Linux 환경의 기준은 [FAQ](/ko/faq/)를 참고하세요.)
2. **Google 계정** — AI를 무료로 사용하기 위해 "API 키"라는 긴 문자열을 하나 만듭니다.
   이 용어가 처음이라도 걱정하지 마세요. 이 페이지에서 차근차근 안내합니다.

## 무료 AI 키 준비 {#prepare-a-free-ai-key}

ZenCopy 자체는 무료지만, 실제 요약과 번역은 외부 AI가 수행합니다 — Gemini나 ChatGPT를 통해 이미 접해 보셨을 그런 AI입니다.
이런 AI를 내 앱에서 사용할 수 있게 해 주는 열쇠가 **API 키**라는 긴 문자열 하나입니다.
집 열쇠와 같다고 생각하세요. **나만의 것이고, 누구에게도 보여 주지 않습니다**.
기억할 것은 그게 전부입니다.

가장 쉬운 방법은 Google의 무료 키입니다:

<Steps>

1. [Google AI Studio의 API 키 페이지](https://aistudio.google.com/api-keys)를 열고 Google 계정으로 로그인하세요.

2. **Create API key** 버튼을 누르세요.

3. 나타나는 긴 문자열(`AIza…`로 시작)을 복사하세요.
   그것이 당신의 API 키입니다.

</Steps>

개인 용도라면 무료 등급으로 충분하며, **결제 수단을 등록하지 않는 한 요금이 청구되지 않는 완전한 무료**입니다.
무료 등급의 한도에 도달해도 요금이 부과되지 않고, 요청이 잠시 멈출 뿐입니다.
한 가지 알아 둘 점: **Google 무료 등급에서는 전송한 내용이 서비스 개선에 사용될 수 있습니다** (Google 약관 기준).
업무상 기밀 문서를 다룬다면 유료 설정으로 전환하거나 [다른 AI 또는 로컬 AI](/ko/configuration/)를 선택하세요.

## 첫 실행 {#first-launch}

1. ZenCopy를 시작해도 창이 바로 열리지는 않습니다.
   화면 가장자리의 작은 아이콘 영역(Windows는 작업 표시줄 오른쪽 아래, Mac은 화면 위쪽 메뉴 막대)에 자리를 잡습니다.
2. 맨 처음 실행하면 짧은 환영 화면이 열립니다.
   방금 복사한 API 키를 붙여넣고 **이 키로 시작**을 누르세요.
   **설정은 이것으로 끝입니다.**
3. 복사한 내용은 설정한 AI 서비스로 **직접** 전송됩니다.
   중간에 중계 서버도 없고, 사용 추적도 없습니다.

Google 외의 AI(OpenAI, Anthropic, 사내 게이트웨이, 로컬 Ollama 등)를 사용하려면 **다른 방법으로 설정**을 선택하고 설정 화면에서 고르세요.

## 일상적인 사용 {#everyday-use}

1. 아무 앱에서나 텍스트를 선택하고 **<span data-os-modifier>Ctrl/⌘</span> + C + C**를 누르세요.
2. 화면 구석에 팝업이 나타나고 결과가 실시간으로 흘러나옵니다.
3. 결과 위의 라벨("요약", "번역", …)은 **전환 스위치**입니다.
   클릭하면 같은 복사 내용에 다른 프롬프트를 실행할 수 있습니다.
   이미 본 결과는 보관되므로 이전 결과로 즉시 전환됩니다 — 프롬프트를 다시 실행하는 것은 **다시 시도**뿐입니다.
   라벨 옆의 ☆를 누르면 그 프롬프트가 새 기본이 됩니다.
4. 각 답변 아래에는 작은 **복사**와 **다시 시도** 버튼이 있습니다. 다시 시도하면 대화가 그 답변까지 되감겨 다시 실행되고, 생성 중인 답변은 **중지**할 수 있습니다.
   결과 아래 입력란에서 답장하면 대화를 계속할 수 있습니다.
   **Esc** 또는 닫기 버튼으로 닫습니다. 헤더를 드래그하면 이동하고, 가장자리를 드래그하면 크기를 조절할 수 있습니다.
5. 결과를 너무 빨리 닫았나요? 트레이 메뉴의 **앱 표시**로 마지막 결과를 언제든 다시 볼 수 있습니다.

네 가지 프롬프트가 기본으로 제공됩니다:
**요약**(한 문장으로 응축), **설명**(이해하기 쉽게), **번역**(내 언어로), **다듬기**(초안 정리).
직접 만드는 데 필요한 것은 이름과 원하는 작업의 설명뿐입니다([설정](/ko/configuration/) 참고).

텍스트만이 아닙니다.
스크린샷과 복사한 파일(이미지, PDF, 오디오, 텍스트 파일)도 같은 동작으로 처리됩니다.
이미지나 그 밖의 바이너리 파일을 보내기 전에는 ZenCopy가 한 번 확인을 요청합니다.

## 안전하게 설계됨 {#designed-to-be-safe}

- **평범한 한 번의 복사는 아무 일도 하지 않습니다.** 아무것도 읽지 않고, 아무것도 보내지 않습니다.
- 다른 앱(예: 비밀번호 관리자)이 기밀로 표시한 클립보드 내용은 두 번 복사해도 무시됩니다.
- 내용은 직접 설정한 AI 서비스로만 전송됩니다.
