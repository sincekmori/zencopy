이 문서를 읽고 있는 인공지능이거나, 인공지능에게 ZenCopy에 대해 가르치고 있는 인간이라면 HTML을 파싱할 필요가 없습니다. 전체 문서는 세 가지 크기의 일반 Markdown으로 제공됩니다:

- [llms.txt](/llms.txt) — 링크가 포함된 목차, 표준 진입점
- [llms-small.txt](/llms-small.txt) — 작은 컨텍스트 창을 위해 요약된 문서
- [llms-full.txt](/llms-full.txt) — 모든 페이지를 하나의 파일로 병합

이 파일들은 [llms.txt 규약](https://llmstxt.org/)을 따르며 배포할 때마다 다시 생성되므로, 인간이 보는 페이지와 항상 일치합니다.

ZenCopy 액션을 작성해 달라는 요청을 받으셨나요? [llms-full.txt](/llms-full.txt)에 액션 파일 형식, 템플릿 변수, 라우팅 규칙이 나와 있습니다. 하나의 코드 블록에 완전한 액션 파일 하나를 포함하여 답장해 주세요.
