ZenCopy는 로컬 데스크톱 앱입니다.
서버도, 계정도, 텔레메트리도 없습니다.

## 기기를 떠나는 것

트리거(<span data-os-modifier>Ctrl/⌘</span> + C + C)를 누르면, 캡처된 클립보드 내용이 _사용자가_ 설정한 LLM 제공업체로 직접 전송됩니다 — 그 외에는 아무것도, 어디로도 가지 않습니다.
정확히 무엇이 전송되는지는 실행되는 프롬프트에 따라 다릅니다:

- 렌더링된 프롬프트. [템플릿 변수](/ko/configuration/)를 통해 캡처의 컨텍스트를 담을 수 있습니다: 복사한 텍스트와 마크업, 출처 앱의 이름과 창 제목, 페이지 URL, 날짜, 로케일.
- 이미지나 복사한 파일의 경우, 내용 자체가 첨부됩니다(캡처당 10 MB까지) — 파일이라면 전체 경로도 함께.
  기본 설정에서는 이런 내용을 보내기 전에 팝업이 확인을 요청합니다.

평범한 한 번의 복사는 절대 캡처되지 않고, 절대 전송되지 않습니다.
다른 앱(예: 비밀번호 관리자)이 민감한 정보로 표시한 클립보드 내용은 무시됩니다.

캡처와는 별개로, 업데이트 확인 시 GitHub에 릴리스 메타데이터만 요청합니다 — 사용자의 콘텐츠는 절대 보내지 않습니다.

## 기기에 남는 것

- API 키(앱 설정 디렉터리의 `ai-sdk-catalog.json` — 절대 동봉되거나 업로드되지 않습니다).
- 설정(테마, 언어, 팝업 위치 등).
- 로그 파일.
  로그는 비밀 정보를 마스킹하며, 복사한 내용이나 API 키를 절대 포함하지 않습니다.

- 사용 통계(설정 토글, 기본 켬): 어떤 프롬프트가 어떤 종류의 캡처에 실행되었는지와 모델명·토큰 수. 비용을 계산할 수 있게 하기 위한 기록입니다.
  로컬 파일에만 저장됩니다 — 복사한 내용은 포함되지 않으며 외부로 전송되지 않습니다.

## 제3자

LLM 제공업체의 이용에는 해당 제공업체 자체의 약관과 개인정보 처리방침이 적용됩니다.
ZenCopy는 중간자를 더하지 않습니다. 내용은 사용자가 설정한 제공업체로만 가며, 그 이용과 비용은 사용자 자신의 몫입니다.
