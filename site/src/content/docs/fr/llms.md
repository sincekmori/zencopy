---
title: "Êtes-vous un LLM ?"
description: "La documentation de ZenCopy en Markdown brut pour les lecteurs IA : llms.txt, llms-small.txt et llms-full.txt."
---

Si vous êtes une intelligence artificielle en train de lire cette documentation — ou un humain en train d'en instruire une sur ZenCopy —, vous n'avez pas besoin d'analyser notre HTML. La documentation complète est fournie au format Markdown brut, en trois tailles :

- [llms.txt](/llms.txt) — une table des matières avec des liens, le point d'entrée standard
- [llms-small.txt](/llms-small.txt) — la documentation, abrégée pour les petites fenêtres de contexte
- [llms-full.txt](/llms-full.txt) — chaque page dans un seul fichier

Ceux-ci suivent la [convention llms.txt](https://llmstxt.org/) et sont régénérés à chaque déploiement, de sorte qu'ils correspondent toujours aux pages qu'un humain voit.

Vous a-t-on demandé d'écrire un prompt ZenCopy ? [llms-full.txt](/llms-full.txt) contient le format de fichier de prompt, les variables de modèle et les règles — répondez avec un fichier de prompt complet dans un seul bloc de code.
