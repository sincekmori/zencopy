ZenCopy funciona desde el primer momento sin configurar nada.
Esta página es para cuando quieres que se adapte mejor a ti.
La primera mitad, sobre la **ventana de ajustes**, es para todos; la segunda mitad, sobre los **archivos de configuración**, es para usuarios avanzados.

## La ventana de ajustes

Ábrela desde el menú del icono de la bandeja o desde el icono de engranaje del popup.
Tiene tres pestañas: **General, IA y Prompts**.

### General

- **Posición del popup** — en qué esquina de la pantalla aparecen los resultados.
- **Tema** — claro / oscuro / seguir el sistema.
- **Tamaño del texto** — Pequeño / Estándar / Grande.
- **Idioma de la interfaz** — por defecto sigue el de tu sistema operativo.
- **Iniciar al iniciar sesión** — que ZenCopy esté esperando siempre que tu computadora esté encendida.
- **Confirmar antes de enviar imágenes y archivos** — si se pregunta una vez antes de que vayan a la IA.

### IA

Aquí es donde cambias el servicio de IA (proveedor, modelo, clave de API).
El botón **Probar** te dice al momento si la conexión funciona.

La pestaña también tiene un campo **Sobre ti**.
Es un lugar para describir tu rol y tus preferencias en unas pocas frases sencillas, en el idioma que quieras.

> Ejemplo: "Ventas. Escribo sobre todo correos a clientes — cordiales pero no rígidos, la conclusión primero."

Con esto rellenado, cada prompt adapta sus resultados a ti.
Las explicaciones llegan a tu nivel de conocimiento y los borradores vuelven en tu tono preferido.
Nunca afecta a tareas sin relación, y el texto en sí nunca aparece en los resultados.

### Prompts

La lista de "qué pasa después de un doble copiado".

- Los prompts preinstalados se pueden abrir y leer — sirven también como ejemplos resueltos.
- Crear un **Nuevo prompt** no requiere más que un nombre y lo que quieres que se haga.
  Por ejemplo: nombre "Resumen en 3 líneas", instrucción "Resume esto en 3 líneas".
- ¿No te sientes seguro escribiendo instrucciones? Anota más o menos lo que quieres y pulsa **Redactar con IA** — la IA que configuraste lo convierte en una instrucción bien formada.
- **Reglas** te permite elegir un prompt distinto según el tipo de contenido (texto / imagen / archivos).

Los prompts que creas se pueden compartir: **Exportar (.md)** escribe uno como archivo, y quien lo recibe solo tiene que pegarlo en **Importar** o elegir el archivo.

¿Prefieres dejar todo el trabajo en manos de una IA? Cualquier chat de IA puede escribir un prompt listo para importar por ti: pega esto y rellena el espacio en blanco:

```text
Lee https://zencopy.app/llms-full.txt, la documentación completa de ZenCopy, incluido el formato del archivo de prompt, las variables de plantilla y cómo funcionan las reglas. Luego, escribe un prompt de ZenCopy que haga lo siguiente: [lo que quieras]. Genera un archivo de prompt completo (Markdown con frontmatter) en un solo bloque de código, listo para pegar en Configuración → Prompts → Importar de ZenCopy. Si el prompt solo tiene sentido en una aplicación específica o en un sitio específico, añade una frase que me indique qué regla configurar.
```

El bloque de código de la respuesta va directo a **Configuración → Prompts → Importar**.
Para preguntas que la documentación no puede responder («¿podría ZenCopy siquiera hacer...?»), <RepomixLink>un clic empaqueta el código fuente relevante</RepomixLink>; entrega el resultado a la misma IA.

## Archivos de configuración (para usuarios avanzados)

De aquí en adelante, esta página trata de editar archivos de texto directamente.
**Todo lo esencial está disponible desde la ventana de ajustes, así que puedes dejar de leer aquí sin perderte nada.**

Los archivos se leen del directorio de configuración de la aplicación de cada usuario.
La ruta exacta también se imprime en el log al arrancar:

<Tabs syncKey="os">
  <TabItem label="Windows">`%APPDATA%\app.zencopy`</TabItem>
  <TabItem label="macOS">`~/Library/Application Support/app.zencopy`</TabItem>
  <TabItem label="Linux">`~/.config/app.zencopy`</TabItem>
</Tabs>

Los valores predeterminados de las reglas van incorporados en la aplicación; `rules.json` solo los **sobrescribe**.
Los archivos de prompts son **aditivos**:
definen prompts nuevos, y los integrados son intocables (un archivo local que reclame el id de uno integrado se ignora).
Las ediciones se aplican desde el siguiente disparo — sin reiniciar.

### `ai-sdk-catalog.json`

Proveedores más una correspondencia **rol → modelo**.
La casa del formato de archivo es [ai-sdk-catalog](https://github.com/sincekmori/ai-sdk-utils/tree/main/packages/catalog#readme) — cada campo está documentado allí (incluido un `$schema` para validación y autocompletado en el editor), y [`examples/`](https://github.com/sincekmori/ai-sdk-utils/tree/main/packages/catalog/examples) tiene configuraciones en tres tamaños.
Para puntos de partida al estilo de ZenCopy (lo que escribe la interfaz de ajustes, Ollama local, roles para prompts), consulta las [Recetas](/es/recipes/).

Hay un requisito propio de ZenCopy, no del formato: `roles` siempre debe incluir **`default`**.
Todo prompt se ejecuta con él salvo que su frontmatter nombre otro role, y la prueba de conexión de los ajustes le hace ping.

Las claves de API van directamente en este archivo local (la interfaz de ajustes escribe el mismo formato); nunca salen de tu máquina.
Las variables de entorno no se leen — las aplicaciones gráficas las inicia el sistema operativo, no tu shell, así que las variables exportadas en `.zshrc` y similares nunca les llegan.
El archivo se valida contra el esquema en cada lectura.
Una edición rota aparece como un mensaje claro en el popup y en el editor de ajustes — nada falla en silencio.

### `rules.json`

Qué prompt atiende cada tipo de captura:
un mapa plano `kind → prompt` más una lista opcional `overrides` de mayor prioridad (gana la primera coincidencia).
Los tres tipos son `text`, `image` y `files` (una copia de texto enriquecido cuenta como `text`); de fábrica, el texto se enruta a Zen, y las imágenes y los archivos a Explicar.
El mapa plano se puede editar dentro de la aplicación (Ajustes → Prompts → Reglas), así que solo necesitas tocar este archivo para `overrides`.

```json
{
  "text": "zencopy-zen",
  "image": "zencopy-explain",
  "files": "zencopy-explain",
  "overrides": [{ "when": { "app_name": "Slack", "min_chars": 200 }, "prompt": "summarize" }]
}
```

Condiciones de `when`: `kind` (uno de los tres tipos, coincidencia exacta), `app_name`, `exec_name`, `window_title`, `url` (todas con comodines `*`), `file_name` (un comodín que el nombre de cada archivo copiado debe coincidir, sin distinguir entre mayúsculas y minúsculas — p. ej. `*.pdf`), más `min_chars` / `max_chars`.

Con las capturas `image` y `files`, el contenido en sí se envía al modelo (hasta 10 MB en total por captura).
Los tipos de archivo se detectan por el **contenido**, no por el nombre:
las imágenes, los PDF y el audio se adjuntan tal cual, mientras que los archivos de texto (Markdown, código fuente, CSV, …) se convierten en el texto de la captura (`{{ text }}`) y se comportan exactamente como si hubieras copiado su contenido.
Los documentos de Office (Word, Excel, PowerPoint) también se convierten en texto: se extrae y se envía su contenido, pero no su diseño ni sus imágenes.
Las codificaciones de caracteres se detectan automáticamente, convirtiendo formatos antiguos como Shift_JIS y UTF-16.
Todo lo demás se rechaza con un mensaje claro.
Las rutas completas acompañan al contenido, para que el modelo pueda distinguir los archivos y sepa dónde están.
Como los adjuntos binarios pueden costar más que el texto, el popup pregunta antes de enviarlos (los archivos de texto se ejecutan sin preguntar) — la confirmación se puede desactivar ahí mismo o en Ajustes.

### `prompts/*.md`

Un archivo = un prompt: frontmatter YAML + un cuerpo de prompt en [Liquid](https://liquidjs.com).
Ese mismo archivo único es el formato para compartir — Ajustes → Prompts → Importar lo acepta como texto pegado o como archivo elegido.

```markdown
---
id: summarize
label: Resumir
role: default
instructions: Eres un asistente conciso.
---

Resume lo siguiente en 3 líneas, en {{ locale }}:

{{ text }}
```

| Frontmatter    | Significado                                                                                                                                        |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`           | Nombre al que hace referencia `rules.json` (por defecto: el nombre del archivo) — el prefijo `zencopy-` está reservado a los prompts preinstalados |
| `label`        | Se muestra en el popup                                                                                                                             |
| `role`         | Rol del catálogo con el que se ejecuta (por defecto: `default`)                                                                                    |
| `instructions` | Prompt de sistema (plantilla Liquid)                                                                                                               |

Variables de plantilla, con valores de ejemplo para un párrafo copiado en un navegador:

| Variable             | Ejemplo                                                                   |
| -------------------- | ------------------------------------------------------------------------- |
| `{{ text }}`         | El texto copiado (las copias HTML enriquecidas se convierten en Markdown) |
| `{{ markup }}`       | El código HTML/RTF de una copia enriquecida                               |
| `{{ format }}`       | `html` (o `rtf`; vacío en las copias simples)                             |
| `{{ file_name }}`    | `report.pdf` (el nombre del primer archivo copiado)                       |
| `{{ file_names }}`   | El nombre de cada archivo copiado, uno por línea                          |
| `{{ file_paths }}`   | La ruta completa de cada archivo copiado, una por línea                   |
| `{{ app_name }}`     | `Safari`                                                                  |
| `{{ exec_name }}`    | `Safari` / `chrome.exe`                                                   |
| `{{ exec_path }}`    | `/Applications/Safari.app/Contents/MacOS/Safari`                          |
| `{{ window_title }}` | `Precios – Example`                                                       |
| `{{ url }}`          | `https://example.com/pricing` (solo en navegadores)                       |
| `{{ process_id }}`   | `8123`                                                                    |
| `{{ now }}`          | `2026-07-08 20:15:00`                                                     |
| `{{ locale }}`       | `es`                                                                      |

También hay un filtro `language_name` propio de ZenCopy: `{{ locale | language_name }}` se expande a "Spanish" en lugar de "es", lo que se lee con naturalidad en un prompt.
Para ver los valores reales, activa **Mostrar variables de plantilla** en Ajustes — las variables de cada captura aparecen en el popup como JSON.

Los prompts simples (un nombre y una instrucción) también se pueden crear desde la ventana de ajustes; lo que esta escribe es exactamente este formato de archivo.

#### Plantillas avanzadas

Tanto el frontmatter `instructions` como el cuerpo son plantillas [LiquidJS](https://liquidjs.com/tags/overview.html) completas: los condicionales, los bucles y los [filtros](https://liquidjs.com/filters/overview.html) funcionan todos.
Un solo prompt puede adaptarse al lugar de donde vino la copia:

```markdown
---
id: context-aware
label: Según el contexto
---

{% if url contains "github.com" %}
Revisa este código y señala el mayor riesgo, solo uno:
{% elsif app_name == "Slack" %}
Resume este hilo de chat en 2 líneas:
{% else %}
Explica esto en {{ locale }}:
{% endif %}

{{ text | truncate: 8000 }}
```

## Logs

Los logs estructurados (con los secretos y el contenido copiado omitidos) van a la terminal en desarrollo y a un archivo rotatorio en las versiones publicadas:
