ZenCopy — локальное настольное приложение.
У него нет сервера, аккаунта и телеметрии.

## Что покидает устройство

Когда вы нажимаете триггер (<span data-os-modifier>Ctrl/⌘</span> + C + C), захваченное содержимое буфера обмена отправляется напрямую LLM-провайдеру, которого настроили _вы_, — ничего больше и никуда больше.
Что именно отправляется, зависит от выполняемого промпта:

- Отрендеренный промпт, который может включать контекст захвата как [переменные шаблона](/ru/configuration/#promptsmd): скопированный текст и разметку, имя исходного приложения и заголовок окна, URL страницы, дату и вашу локаль.
- Для изображения или скопированных файлов прикладывается само содержимое (до 10 МБ на захват) — а для файлов ещё и их полные пути.
  По умолчанию всплывающее окно спрашивает перед их отправкой.

Одиночное обычное копирование никогда не захватывается и никогда не отправляется.
Содержимое буфера обмена, которое другие приложения помечают как конфиденциальное (например, менеджеры паролей), игнорируется.

Помимо захватов, проверка обновлений запрашивает у GitHub только метаданные релиза — никогда ваш контент.

## Что остаётся на устройстве

- Ваши ключи API (`ai-sdk-catalog.json` в каталоге конфигурации приложения — никогда не включаются в сборку и никогда не выгружаются).
- Ваши настройки (тема, язык, положение всплывающего окна, …).
- Файлы журналов.
  В журналах секреты скрываются; скопированное содержимое и ключи API в них не попадают никогда.

- Статистика использования (переключатель в настройках, включена по умолчанию): какой промпт выполнялся для какого типа захвата, плюс модель и число токенов, чтобы расходы оставались вычислимыми.
  Только локальный файл — никогда скопированное содержимое, никуда не отправляется.

## Третьи стороны

Ваше использование LLM-провайдера регулируется собственными условиями и политикой конфиденциальности этого провайдера.
ZenCopy не добавляет посредника: ваше содержимое идёт только настроенному вами провайдеру, а его использование и расходы — ваши собственные.
