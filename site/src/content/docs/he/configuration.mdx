ZenCopy עובד מהקופסה בלי להגדיר דבר.
הדף הזה מיועד לרגע שבו תרצו שהוא יתאים לכם יותר.
החצי הראשון, על **חלון ההגדרות**, מיועד לכולם; החצי השני, על **קובצי תצורה**, מיועד למשתמשים מתקדמים.

## חלון ההגדרות

פותחים אותו מהתפריט של אייקון מגש המערכת, או מאייקון גלגל השיניים שבחלון הקופץ.
יש בו שלוש לשוניות: **כללי, AI ופעולות**.

### כללי

- **מיקום החלון הקופץ** — באיזו פינה של המסך יופיעו התוצאות.
- **ערכת נושא** — בהיר / כהה / לפי המערכת.
- **שפה** — שפת הממשק (כברירת מחדל לפי מערכת ההפעלה).
- **הפעלה בכניסה למערכת** — ש‑ZenCopy יחכה לכם בכל פעם שהמחשב דולק.
- **אישור לפני שליחת תמונות וקבצים** — האם לשאול פעם אחת לפני שתמונות או קבצים נשלחים ל‑AI.

### AI

כאן משנים את שירות ה‑AI (ספק, מודל, מפתח API).
כפתור **בדיקה** אומר לכם מיד אם החיבור עובד.

בלשונית יש גם שדה **עליך**.
זה מקום לתאר את התפקיד וההעדפות שלכם בכמה משפטים פשוטים, בכל שפה.

> דוגמה: "איש מכירות. רוב מה שאני כותב הוא מייל ללקוחות — מנומס אבל לא נוקשה, המסקנה קודם."

כשהשדה מלא, כל פעולה מתאימה את התוצאות שלה אליכם.
הסברים מגיעים ברמת הידע שלכם, וטיוטות חוזרות בטון המועדף עליכם.
זה לעולם לא משפיע על משימות לא קשורות, והטקסט עצמו לעולם לא מופיע בתוצאות.

### פעולות

הרשימה של "מה קורה אחרי העתקה כפולה".

- את הפעולות המותקנות מראש אפשר לפתוח ולקרוא — הן משמשות גם כדוגמאות עבודה.
- **פעולה חדשה** דורשת רק שם ומה שאתם רוצים שייעשה.
  לדוגמה: שם "תקציר ב‑3 שורות", הנחיה "סכם את זה ב‑3 שורות".
- לא בטוחים בכתיבת הנחיות? רשמו בערך מה אתם רוצים ולחצו על **ניסוח עם AI** — ה‑AI שהגדרתם יהפוך את זה להנחיה מנוסחת היטב.
- ה‑★ מסמן את פעולת ברירת המחדל — זו שהעתקה כפולה מריצה קודם.
- **ניתוב** מאפשר לבחור פעולה שונה לכל סוג תוכן (טקסט / תמונה / קבצים).

פעולות שבניתם אפשר לשתף: **ייצוא (.md)** כותב פעולה כקובץ, והצד המקבל פשוט מדביק אותה ב**ייבוא** או בוחר את הקובץ.

## קובצי תצורה (למשתמשים מתקדמים)

מכאן והלאה הדף עוסק בעריכה ישירה של קובצי טקסט.
**כל מה שחיוני זמין מחלון ההגדרות, כך שאפשר בהחלט להפסיק לקרוא כאן.**

הקבצים נקראים מתיקיית התצורה של האפליקציה עבור המשתמש.
הנתיב המדויק מודפס גם ליומן בעת ההפעלה:

<Tabs syncKey="os">
  <TabItem label="Windows">`%APPDATA%\app.zencopy`</TabItem>
  <TabItem label="macOS">`~/Library/Application Support/app.zencopy`</TabItem>
  <TabItem label="Linux">`~/.config/app.zencopy`</TabItem>
</Tabs>

ברירות המחדל של הניתוב מוטמעות באפליקציה; `routing.json` רק **עוקף** אותן.
קובצי פעולות הם **תוספתיים**:
הם מגדירים פעולות חדשות, והפעולות המובנות אינן ניתנות לשינוי (ZenCopy מתעלם מקובץ מקומי שמכריז על id של פעולה מובנית).
עריכות נכנסות לתוקף בטריגר הבא — אין צורך בהפעלה מחדש.

### `ai-sdk-catalog.json`

ספקים, ובנוסף מיפוי **role ← model**.
הבית של פורמט הקובץ הוא [ai-sdk-catalog](https://github.com/sincekmori/ai-sdk-utils/tree/main/packages/catalog#readme) — כל שדה מתועד שם (כולל `$schema` לאימות ולהשלמה בעורך), וב‑[`examples/`](https://github.com/sincekmori/ai-sdk-utils/tree/main/packages/catalog/examples) יש תצורות בשלושה גדלים.
לנקודות פתיחה בטעם של ZenCopy (מה שממשק ההגדרות כותב, Ollama מקומי, roles לפעולות), ראו [מתכונים](/he/recipes/).

מפתחות API נכתבים ישירות לקובץ המקומי הזה (ממשק ההגדרות כותב את אותו פורמט בדיוק); הם לעולם לא עוזבים את המחשב שלכם.
משתני סביבה אינם נקראים — אפליקציות GUI מופעלות על ידי מערכת ההפעלה, לא על ידי המעטפת שלכם, ולכן משתנים שיוצאו ב‑`.zshrc` וחבריו לעולם לא מגיעים אליהן.
הקובץ עובר אימות סכמה בכל קריאה.
עריכה שבורה מופיעה כהודעה ברורה בחלון הקופץ ובעורך ההגדרות — שום דבר לא נכשל בשקט.

### `routing.json`

איזו פעולה מטפלת באיזה סוג של לכידה:
מפה שטוחה של kind ← action, ובנוסף רשימת `overrides` אופציונלית בעדיפות גבוהה יותר (ההתאמה הראשונה מנצחת).
ארבעת הסוגים הם `text`‏, `rich_text`‏, `image` ו‑`files`; מהקופסה, טקסט מנותב אל Zen, ותמונות וקבצים מנותבים אל "הסבר".
המפה השטוחה ניתנת לעריכה בתוך האפליקציה (הגדרות ← פעולות ← ניתוב), ולכן צריך לגעת בקובץ הזה רק בשביל `overrides`.

```json
{
  "text": "zen",
  "rich_text": "zen",
  "image": "explain",
  "files": "explain",
  "overrides": [{ "when": { "app_name": "Slack", "min_chars": 200 }, "action": "summarize" }]
}
```

תנאי `when`‏: `kind`‏, `app_name`‏, `exec_name`‏, `window_title`‏, `url` (כולם עם תווים כלליים `*`), ובנוסף `min_chars` / `max_chars`.

בלכידות `image` ו‑`files`, התוכן עצמו נשלח למודל (עד 10 מ״ב בסך הכול ללכידה).
סוגי קבצים מזוהים לפי **התוכן**, לא לפי השמות:
תמונות, קובצי PDF ושמע מצורפים כמו שהם, בעוד קובצי טקסט (Markdown, קוד מקור, CSV, …) הופכים לטקסט של הלכידה (`{{ text }}`) ומתנהגים בדיוק כאילו העתקתם את תוכנם.
קידודי תווים מזוהים אוטומטית, כולל המרה של פורמטים ישנים כמו Shift_JIS ו‑UTF-16.
כל דבר אחר נדחה עם הודעה ברורה.
הנתיבים המלאים נשלחים יחד עם התוכן, כדי שהמודל יוכל להבדיל בין הקבצים ולדעת איפה הם נמצאים.
מכיוון שצירופים בינאריים עלולים לעלות יותר מטקסט, החלון הקופץ שואל לפני שליחתם (קובצי טקסט רצים בלי לשאול) — אפשר לכבות את האישור במקום או בהגדרות.

### `actions/*.md`

קובץ אחד = פעולה אחת: frontmatter של YAML + גוף פרומפט של [Liquid](https://liquidjs.com).
אותו קובץ יחיד הוא גם פורמט השיתוף — הגדרות ← פעולות ← ייבוא מקבל אותו כטקסט מודבק או כקובץ נבחר.

```markdown
---
id: summarize
label: סיכום
role: default
instructions: אתה עוזר תמציתי.
---

סכם את זה ב‑3 שורות, בשפה {{ locale }}:

{{ text }}
```

| Frontmatter    | משמעות                                                 |
| -------------- | ------------------------------------------------------ |
| `id`           | השם שאליו מפנה `routing.json` (ברירת מחדל: שם הקובץ)   |
| `label`        | מוצג בחלון הקופץ                                       |
| `role`         | ה‑role בקטלוג שאיתו הפעולה רצה (ברירת מחדל: `default`) |
| `instructions` | פרומפט מערכת (תבנית Liquid)                            |

משתני התבנית, עם ערכי דוגמה לפסקה שהועתקה בדפדפן:

| משתנה                | דוגמה                                               |
| -------------------- | --------------------------------------------------- |
| `{{ text }}`         | הטקסט שהועתק (העתקות HTML עשירות הופכות ל‑Markdown) |
| `{{ markup }}`       | מקור ה‑HTML/RTF של העתקה עשירה                      |
| `{{ format }}`       | `html` (או `rtf`; ריק בהעתקות רגילות)               |
| `{{ app_name }}`     | `Safari`                                            |
| `{{ exec_name }}`    | `Safari` / `chrome.exe`                             |
| `{{ exec_path }}`    | `/Applications/Safari.app/Contents/MacOS/Safari`    |
| `{{ window_title }}` | `תמחור – Example`                                   |
| `{{ url }}`          | `https://example.com/pricing` (בדפדפנים בלבד)       |
| `{{ process_id }}`   | `8123`                                              |
| `{{ now }}`          | `2026-07-08 20:15:00`                               |
| `{{ locale }}`       | `he`                                                |

יש גם מסנן ייחודי ל‑ZenCopy בשם `language_name`‏: `{{ locale | language_name }}` מתרחב ל‑"Hebrew" ולא ל‑"he", מה שנקרא טבעי בתוך פרומפט.
כדי לראות את הערכים האמיתיים, הפעילו את **מצב מפתחים** בהגדרות — משתני התבנית של כל לכידה יופיעו בחלון הקופץ כ‑JSON.

פעולות פשוטות (שם והנחיה) אפשר ליצור גם מחלון ההגדרות; מה שהוא כותב הוא בדיוק פורמט הקובץ הזה.

#### תבניות מתקדמות

גם ה‑frontmatter של `instructions` וגם הגוף הם תבניות [LiquidJS](https://liquidjs.com/tags/overview.html) מלאות: תנאים, לולאות ו[מסננים](https://liquidjs.com/filters/overview.html) — הכול עובד.
פעולה אחת יכולה להסתגל למקום שממנו הגיעה ההעתקה:

```markdown
---
id: context-aware
label: מודע להקשר
---

{% if url contains "github.com" %}
בדוק את הקוד הזה והצבע על הסיכון הגדול ביותר:
{% elsif app_name == "Slack" %}
סכם את שרשור הצ'אט הזה בשתי שורות:
{% else %}
הסבר את זה בשפה {{ locale }}:
{% endif %}

{{ text | truncate: 8000 }}
```
