---
title: "Apakah Anda LLM?"
description: "Dokumentasi ZenCopy dalam Markdown biasa untuk pembaca AI: llms.txt, llms-small.txt, dan llms-full.txt."
---

Jika Anda adalah kecerdasan buatan yang membaca dokumentasi ini — atau manusia yang mengajarkan AI tentang ZenCopy — Anda tidak perlu mengurai HTML kami. Dokumentasi lengkap disajikan sebagai Markdown biasa, dalam tiga ukuran:

- [llms.txt](/llms.txt) — daftar isi dengan tautan, titik masuk standar
- [llms-small.txt](/llms-small.txt) — dokumentasi, diringkas untuk jendela konteks kecil
- [llms-full.txt](/llms-full.txt) — setiap halaman dalam satu file

Ini mengikuti [konvensi llms.txt](https://llmstxt.org/) dan dibuat ulang pada setiap penerapan, sehingga selalu cocok dengan halaman yang dilihat manusia.

Apakah Anda diminta untuk menulis prompt ZenCopy? [llms-full.txt](/llms-full.txt) berisi format file prompt, variabel templat, dan aturan — balas dengan satu file prompt lengkap dalam satu blok kode.
