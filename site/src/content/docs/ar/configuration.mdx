يعمل ZenCopy فور تثبيته دون ضبط أي شيء.
هذه الصفحة لمن يريده أن يلائمه أكثر.
النصف الأول، عن **نافذة الإعدادات**، موجّه للجميع؛ والنصف الثاني، عن **ملفات الإعداد**، موجّه للمستخدمين المتقدمين.

## نافذة الإعدادات

افتحها من قائمة أيقونة النظام، أو من أيقونة الترس في النافذة المنبثقة.
تضم ثلاثة تبويبات: **عام والذكاء الاصطناعي والإجراءات**.

### عام

- **موضع النافذة المنبثقة** — في أي زاوية من الشاشة تظهر النتائج.
- **المظهر** — فاتح / داكن / يتبع النظام.
- **اللغة** — لغة العرض (تتبع نظام التشغيل افتراضيًا).
- **التشغيل عند تسجيل الدخول** — ليكون ZenCopy جاهزًا كلما كان حاسوبك يعمل.
- **التأكيد قبل الإرسال** — هل يُسأل مرة قبل إرسال الصور أو الملفات إلى الذكاء الاصطناعي.

### الذكاء الاصطناعي

هنا تغيّر خدمة الذكاء الاصطناعي (المزوّد والنموذج ومفتاح API).
زر **اختبار** يخبرك فورًا هل الاتصال يعمل أم لا.

يضم التبويب أيضًا حقل **نبذة عنك**.
وهو مكان تصف فيه دورك وتفضيلاتك في بضع جمل بسيطة وبأي لغة.

> مثال: «مبيعات. أكتب غالبًا رسائل بريد للعملاء — مهذبة دون جمود، والخلاصة أولًا.»

بملء هذا الحقل، يكيّف كل إجراء نتائجه لتناسبك.
فتصلك الشروح على قدر معرفتك، وتعود المسودات بالأسلوب الذي تفضّله.
ولا يؤثر أبدًا في المهام غير ذات الصلة، ولا يظهر النص نفسه في النتائج قط.

### الإجراءات

قائمة «ما الذي يحدث بعد النسخ المزدوج».

- الإجراءات المثبّتة مسبقًا يمكن فتحها وقراءتها — فهي تصلح أمثلة عملية أيضًا.
- **الإجراء الجديد** لا يتطلب سوى اسم وما تريد إنجازه.
  مثلًا: الاسم «تلخيص في ثلاثة أسطر»، والتعليمات «لخِّص هذا في ثلاثة أسطر».
- لست واثقًا من كتابة التعليمات؟ دوّن ما تريده ولو تقريبيًا واضغط **صياغة بالذكاء الاصطناعي** — يحوّله الذكاء الاصطناعي الذي أعددته إلى تعليمات سليمة الصياغة.
- **التوجيه** يتيح لك اختيار إجراء مختلف لكل نوع من المحتوى (نص / صورة / ملفات).

الإجراءات التي تبنيها قابلة للمشاركة: **تصدير (.md)** يكتب الإجراء ملفًا، والطرف المستقبِل يلصقه ببساطة في **استيراد** أو يختار الملف.

## ملفات الإعداد (للمستخدمين المتقدمين)

من هنا فصاعدًا، تتناول هذه الصفحة تحرير الملفات النصية مباشرة.
**كل ما هو أساسي متاح من نافذة الإعدادات، فلا حرج في التوقف عن القراءة هنا.**

تُقرأ الملفات من دليل إعدادات التطبيق الخاص بكل مستخدم.
ويُطبع المسار الدقيق أيضًا في السجل عند بدء التشغيل:

<Tabs syncKey="os">
  <TabItem label="Windows">`%APPDATA%\app.zencopy`</TabItem>
  <TabItem label="macOS">`~/Library/Application Support/app.zencopy`</TabItem>
  <TabItem label="Linux">`~/.config/app.zencopy`</TabItem>
</Tabs>

الإعدادات الافتراضية للتوجيه مضمّنة في التطبيق؛ وملف `routing.json` لا يفعل سوى **تجاوزها**.
أما ملفات الإجراءات فهي **إضافية**:
تعرّف إجراءات جديدة، والإجراءات المضمّنة لا تُمس (أي ملف محلي يدّعي id إجراء مضمّن يُتجاهل).
التعديلات تسري عند التشغيل التالي — دون حاجة إلى إعادة تشغيل.

### `ai-sdk-catalog.json`

المزوّدون إضافة إلى ربط **role ← model**.
موطن صيغة الملف هو [ai-sdk-catalog](https://github.com/sincekmori/ai-sdk-utils/tree/main/packages/catalog#readme) — كل حقل موثّق هناك (بما في ذلك `$schema` للتحقق والإكمال التلقائي في المحرر)، ويضم [`examples/`](https://github.com/sincekmori/ai-sdk-utils/tree/main/packages/catalog/examples) إعدادات بثلاثة أحجام.
ولنقاط انطلاق بنكهة ZenCopy (ما تكتبه واجهة الإعدادات، وOllama المحلي، والأدوار للإجراءات)، راجع [الوصفات](/ar/recipes/).

تُوضع مفاتيح API مباشرة في هذا الملف المحلي (واجهة الإعدادات تكتب الصيغة نفسها)؛ ولا تغادر جهازك أبدًا.
متغيرات البيئة لا تُقرأ — فتطبيقات الواجهة الرسومية يشغّلها نظام التشغيل لا الـ shell الخاص بك، لذا لا تصلها المتغيرات المصدَّرة في `.zshrc` وأشباهه.
يُتحقق من الملف وفق المخطط عند كل قراءة.
وأي تعديل معطوب يظهر رسالة واضحة في النافذة المنبثقة وفي محرر الإعدادات — لا شيء يفشل بصمت.

### `routing.json`

أي إجراء يتولى أي نوع من الالتقاط:
خريطة مسطّحة `kind ← action` إضافة إلى قائمة `overrides` اختيارية أعلى أولوية (أول تطابق يفوز).
الأنواع الأربعة هي `text` و`rich_text` و`image` و`files`؛ وافتراضيًا يوجَّه النص إلى Zen، وتوجَّه الصور والملفات إلى «شرح».
الخريطة المسطّحة قابلة للتحرير داخل التطبيق (الإعدادات ← الإجراءات ← التوجيه)، فلا تحتاج إلى لمس هذا الملف إلا من أجل `overrides`.

```json
{
  "text": "zen",
  "rich_text": "zen",
  "image": "explain",
  "files": "explain",
  "overrides": [{ "when": { "app_name": "Slack", "min_chars": 200 }, "action": "summarize" }]
}
```

شروط `when`: هي `kind` و`app_name` و`exec_name` و`window_title` و`url` (وكلها تدعم البدل `*`)، و`file_name` (بدل يجب أن يطابق اسم كل ملف منسوخ، دون اعتبار لحالة الأحرف — مثل `*.pdf`)، إضافة إلى `min_chars` / `max_chars`.

في التقاطات `image` و`files`، يُرسل المحتوى نفسه إلى النموذج (حتى 10 م.ب. إجمالًا لكل التقاط).
أنواع الملفات تُكتشف من **المحتوى** لا من الأسماء:
الصور وملفات PDF والصوت تُرفق كما هي، بينما تصبح الملفات النصية (Markdown والشيفرة المصدرية وCSV …) نصَّ الالتقاط نفسه (`{{ text }}`) وتُعامل تمامًا كما لو نسخت محتوياتها.
تصبح مستندات Office (Word وExcel وPowerPoint) نصًا أيضًا: يتم استخراج محتواها وإرساله، بينما لا يتم إرسال تصميمها وصورها.
ترميزات الأحرف تُكتشف تلقائيًا، مع تحويل الصيغ القديمة مثل Shift_JIS وUTF-16.
وأي شيء آخر يُرفض مع رسالة واضحة.
تُرسل المسارات الكاملة مع المحتويات ليتمكن النموذج من التمييز بين الملفات ومعرفة مواضعها.
ولأن المرفقات الثنائية قد تكلّف أكثر من النص، تسأل النافذة المنبثقة قبل إرسالها (الملفات النصية تعمل دون سؤال) — ويمكن إيقاف التأكيد في مكانه أو من الإعدادات.

### `actions/*.md`

ملف واحد = إجراء واحد: frontmatter بصيغة YAML + نص موجّه بصيغة [Liquid](https://liquidjs.com).
والملف الواحد نفسه هو صيغة المشاركة — الإعدادات ← الإجراءات ← استيراد يقبله نصًا ملصوقًا أو ملفًا مختارًا.

```markdown
---
id: summarize
label: تلخيص
role: default
instructions: أنت مساعد موجز.
---

لخِّص في ثلاثة أسطر بلغة {{ locale }}:

{{ text }}
```

| الـ frontmatter | المعنى                                                      |
| --------------- | ----------------------------------------------------------- |
| `id`            | الاسم المُشار إليه من `routing.json` (افتراضيًا: اسم الملف) |
| `label`         | يُعرض في النافذة المنبثقة                                   |
| `role`          | دور الـ catalog الذي يُشغَّل به (افتراضيًا: `default`)      |
| `instructions`  | موجّه النظام (قالب Liquid)                                  |

متغيرات القالب، مع أمثلة قيمها لفقرة نُسخت في متصفح:

| المتغير              | مثال                                             |
| -------------------- | ------------------------------------------------ |
| `{{ text }}`         | النص المنسوخ (نسخ HTML المنسّقة تصبح Markdown)   |
| `{{ markup }}`       | مصدر HTML/RTF لنسخة منسّقة                       |
| `{{ format }}`       | `html` (أو `rtf`؛ فارغ للنسخ العادية)            |
| `{{ file_name }}`    | `report.pdf` (اسم أول ملف منسوخ)                 |
| `{{ file_names }}`   | اسم كل ملف منسوخ، كل اسم في سطر                  |
| `{{ file_paths }}`   | المسار الكامل لكل ملف منسوخ، كل مسار في سطر      |
| `{{ app_name }}`     | `Safari`                                         |
| `{{ exec_name }}`    | `Safari` / `chrome.exe`                          |
| `{{ exec_path }}`    | `/Applications/Safari.app/Contents/MacOS/Safari` |
| `{{ window_title }}` | `الأسعار – Example`                              |
| `{{ url }}`          | `https://example.com/pricing` (المتصفحات فقط)    |
| `{{ process_id }}`   | `8123`                                           |
| `{{ now }}`          | `2026-07-08 20:15:00`                            |
| `{{ locale }}`       | `ar`                                             |

يوجد أيضًا مرشِّح `language_name` خاص بـ ZenCopy: يتوسّع `{{ locale | language_name }}` إلى "Arabic" بدل "ar"، فيُقرأ داخل الموجّه قراءة طبيعية.
ولرؤية القيم الفعلية، فعِّل **وضع المطوّر** من الإعدادات — فتظهر متغيرات القالب لكل التقاط في النافذة المنبثقة بصيغة JSON.

الإجراءات البسيطة (اسم وتعليمات) يمكن إنشاؤها أيضًا من نافذة الإعدادات؛ وما تكتبه هو هذه الصيغة من الملفات بالضبط.

#### قوالب متقدمة

كل من frontmatter الخاص بـ `instructions` والنص الأساسي قالبان كاملان بصيغة [LiquidJS](https://liquidjs.com/tags/overview.html): الشروط والحلقات و[المرشّحات](https://liquidjs.com/filters/overview.html) كلها تعمل.
ويمكن لإجراء واحد أن يتكيف بحسب مصدر النسخ:

```markdown
---
id: context-aware
label: حسب السياق
---

{% if url contains "github.com" %}
راجع هذه الشيفرة وأشر إلى أكبر خطر واحد فيها:
{% elsif app_name == "Slack" %}
لخِّص سلسلة المحادثة هذه في سطرين:
{% else %}
اشرح هذا بلغة {{ locale }}:
{% endif %}

{{ text | truncate: 8000 }}
```
