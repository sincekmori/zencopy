title: "هل أنت LLM؟"
description: "وثائق ZenCopy بتنسيق Markdown بسيط للقراء من الذكاء الاصطناعي: llms.txt و llms-small.txt و llms-full.txt."
---

إذا كنت ذكاءً اصطناعيًا يقرأ هذه الوثائق — أو بشريًا يعلم ذكاءً اصطناعيًا عن ZenCopy — فلست بحاجة إلى تحليل كود HTML الخاص بنا. تتوفر الوثائق الكاملة بتنسيق Markdown بسيط، بثلاثة أحجام:

- [llms.txt](/llms.txt) — جدول محتويات يحتوي على روابط، وهو نقطة الدخول القياسية
- [llms-small.txt](/llms-small.txt) — الوثائق، مختصرة لنوافذ السياق الصغيرة
- [llms-full.txt](/llms-full.txt) — كل صفحة في ملف واحد

تتبع هذه الملفات [اتفاقية llms.txt](https://llmstxt.org/) ويتم إعادة إنشائها مع كل عملية نشر، لذا فهي تطابق دائمًا الصفحات التي يراها البشر.
