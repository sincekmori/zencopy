# zencopy.app

The ZenCopy homepage and documentation: an [Astro](https://astro.build) + [Starlight](https://starlight.astro.build) static site in all 19 languages the app supports.

```sh
bun install
bun run dev        # local dev server
bun run build      # static build into dist/ (starlight-links-validator fails it on stale links or anchors)
bun run deploy     # build + deploy to Cloudflare Workers (needs `wrangler login`)
```

Docs content lives in [src/content/docs/](src/content/docs/), one directory per locale code (`en/`, `ja/`, …) — there is no root locale.
The landing page is rendered per locale by [src/components/Landing.astro](src/components/Landing.astro) through `src/pages/<code>/index.astro`, with its copy in [src/components/landing-copy.ts](src/components/landing-copy.ts); the bare `/` redirects by browser language ([src/pages/index.astro](src/pages/index.astro)).
`/privacy` and `/terms` are linked from the landing footer and the docs sidebar.
Per-locale assets live under `public/<code>/` — docs screenshots (generated by `bun run screenshot` at the repo root) and demo videos.
Deployment is configured in [wrangler.jsonc](wrangler.jsonc).
